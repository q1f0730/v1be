向量嵌入 (Embedding)

Embeddings

📐 01 · 定义

向量嵌入（Embedding）是把文本、图像等离散对象映射为固定长度稠密向量的表示方法，语义相近的对象在向量空间中距离更近。它属于表示层，是语义检索、RAG、聚类、去重和推荐的基础。嵌入由专门的嵌入模型生成，常见维度从几百到几千。

⚙️ 02 · 原理
  1. 1

    文本先被分词为 token，输入嵌入模型（通常是 Transformer 编码器）。

  2. 2

    模型对各 token 的隐藏状态做池化（如均值池化或取特定 token），得到一个固定维度向量。

  3. 3

    训练常用对比学习：拉近语义相关的文本对，推远不相关的，从而让距离反映语义。

  4. 4

    使用时对查询和文档分别编码，用余弦相似度或点积计算相关度；向量归一化后两者排序等价。

  5. 5

    向量写入向量数据库或索引，配合近似最近邻（ANN）算法在大规模数据中快速检索。

🔤 03 · 术语
余弦相似度 (Cosine Similarity)
两向量夹角的余弦，范围 -1 到 1，常用于衡量语义相似。
维度 (Dimensionality)
向量长度，影响表达力、存储与检索成本。
对比学习 (Contrastive Learning)
通过正负样本对训练，使相似样本向量靠近。
Matryoshka 表示
训练使向量前若干维也可单独使用，便于截断降维。
非对称检索 (Asymmetric Retrieval)
短查询匹配长文档，部分模型需给查询和文档加不同前缀。
💻 04 · 代码
生成嵌入并计算相似度python
import numpy as np
from openai import OpenAI

client = OpenAI()
texts = ["如何重置密码", "忘记登录密码怎么办", "今天天气不错"]
resp = client.embeddings.create(model="text-embedding-3-small", input=texts)
vecs = np.array([d.embedding for d in resp.data])

# 归一化后点积即余弦相似度
vecs = vecs / np.linalg.norm(vecs, axis=1, keepdims=True)
sim = vecs @ vecs.T

print(vecs.shape)              # (3, 1536)
print(round(sim[0, 1], 3))     # 语义相近，分数较高
print(round(sim[0, 2], 3))     # 无关，分数较低

text-embedding-3-small 默认 1536 维；相似度绝对值因模型而异，只比较相对大小。

🕳️ 07 · 常见坑

  • ✗更换嵌入模型后只给新文档编码

    ✓不同模型向量空间不兼容，必须全量重建索引

  • ✗设一个固定阈值判断“相关”

    ✓阈值随模型和语料变化，用标注数据校准

  • ✗整篇长文直接编码成一个向量

    ✓按语义分块后编码，避免信息被平均稀释

  • ✗忽略模型要求的查询/文档前缀

    ✓按模型文档为查询和文档添加对应指令前缀

🎤 09 · 面试追问
为什么常用余弦相似度而非欧氏距离？

余弦只看方向不看长度，对文本长度等造成的范数差异不敏感。很多嵌入模型输出已归一化，此时余弦、点积与欧氏距离的排序完全等价，点积计算最快，所以向量库常直接用内积。

嵌入检索的典型失败场景有哪些？

专有名词、型号、编号等精确匹配需求，稠密向量容易漏；否定和数字比较语义难以区分；领域术语与通用语料差异大。常见补救是加 BM25 混合检索、用重排模型精排，或用领域数据微调嵌入模型。

向量维度越高越好吗？

不一定。高维表达力更强，但存储、内存和检索延迟按维度线性增长，收益递减。支持 Matryoshka 的模型可以截断维度，在质量和成本间取舍，应以自己的检索评测结果决定。
