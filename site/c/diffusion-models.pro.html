扩散模型 (图像 / 视频生成)

Diffusion Models

📐 01 · 定义

扩散模型（Diffusion Model）是一类生成模型：训练时学习逆转「逐步向数据加噪」的过程，生成时从纯噪声出发，迭代去噪得到图像、视频或音频。Stable Diffusion 等潜空间扩散在压缩后的潜变量上去噪以降低成本，并通过文本编码器与无分类器引导实现文生图。它是当前主流图像与视频生成的基础方法之一。

⚙️ 02 · 原理
  1. 1

    前向过程：按预设噪声调度，逐步向训练图像添加高斯噪声，直到接近纯噪声。

  2. 2

    训练：网络（U-Net 或 Transformer）学习在给定时间步和条件下预测所加噪声（或等价目标）。

  3. 3

    条件注入：文本经编码器（如 CLIP、T5）转为向量，通过交叉注意力等方式引导去噪方向。

  4. 4

    采样：从随机噪声开始，由调度器按若干步迭代去噪；步数越少越快，但质量可能下降。

  5. 5

    潜空间扩散先用 VAE 把图像压缩到潜空间，在潜空间去噪后再解码回像素，显著降低显存与计算。

🔤 03 · 术语
去噪网络 (Denoiser)
预测并去除噪声的神经网络，常用 U-Net 或 DiT。
调度器 (Scheduler / Sampler)
决定每步噪声水平与更新规则的算法。
无分类器引导 (CFG)
混合有条件与无条件预测，guidance_scale 越大越贴合提示。
潜空间 (Latent Space)
VAE 压缩后的低维表示，在其中去噪更省算力。
种子 (Seed)
初始噪声的随机种子，固定后可复现相同结果。
💻 04 · 代码
用 diffusers 文生图python
# pip install diffusers transformers accelerate torch
import torch
from diffusers import StableDiffusionPipeline

pipe = StableDiffusionPipeline.from_pretrained(
    "stable-diffusion-v1-5/stable-diffusion-v1-5",
    torch_dtype=torch.float16,
).to("cuda")

generator = torch.Generator("cuda").manual_seed(42)   # 固定种子可复现
image = pipe(
    prompt="a cozy bubble tea shop at night, watercolor, warm light",
    negative_prompt="blurry, extra fingers, watermark",
    num_inference_steps=30,     # 去噪步数
    guidance_scale=7.5,         # CFG 强度
    generator=generator,
).images[0]
image.save("shop.png")

需 NVIDIA GPU；使用前请阅读模型许可证。步数、CFG 与种子是最常调的三个参数。

📊 05 · 参数对比

关键采样参数

参数作用过大/过小的影响
num_inference_steps去噪迭代次数过少粗糙，过多变慢且收益递减
guidance_scale贴合提示的强度过大过饱和失真，过小偏离提示
seed初始噪声固定可复现，改变得到不同构图
分辨率输出尺寸偏离训练分辨率易出现重复与畸变
⚖️ 06 · 方案取舍

本地开放权重模型

优点可控、可微调（LoRA）、无按张费用

代价需 GPU 与调参经验

适用批量生成、风格定制

托管图像 API

优点质量高、免部署

代价按次计费，内容政策受限

适用产品集成、低运维

少步蒸馏模型

优点一到数步出图，速度快

代价细节与多样性可能下降

适用实时预览、交互式生成

🕳️ 07 · 常见坑

  • ✗CFG 调得很高以求「更听话」

    ✓在常用范围内调整，并改进提示词本身

  • ✗在远离训练分辨率的尺寸直接生成

    ✓按模型原生分辨率生成，再放大或用分块方法

  • ✗忽视模型许可证与生成内容的版权、肖像风险

    ✓核对许可证与平台政策，建立内容审核

  • ✗不记录种子与参数，好结果无法复现

    ✓保存提示、参数、种子与模型版本

🎤 09 · 面试追问
扩散模型和 GAN 相比有什么优势与代价？

扩散模型训练更稳定、模式覆盖更好、多样性高，且易于加入文本等条件；代价是采样需多步迭代、推理较慢，因此出现了更快的调度器、蒸馏与一致性模型等加速方法。

无分类器引导是怎么工作的？

训练时随机丢弃条件，使同一网络学会有条件和无条件预测；采样时把两者按 guidance_scale 外推组合，放大条件方向的影响，换取更贴合提示但多样性下降。

为什么要在潜空间做扩散？

像素空间维度高，迭代去噪计算与显存开销大；先用 VAE 压缩到低维潜空间，在其中去噪再解码，能大幅降低成本，同时保留感知质量，这是 Latent Diffusion 的核心思想。
