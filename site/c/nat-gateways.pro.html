NAT Gateways

📐 01 · 定义

NAT 网关（NAT Gateway）是网络层组件，对私有子网发出的流量做源地址转换（SNAT），把内网 IP 替换为公网 IP，让无公网地址的服务器能主动访问互联网（拉依赖、调外部 API），同时外部无法主动发起连接进入。云上通常是托管服务，按小时和流量计费。

⚙️ 02 · 原理
  1. 1

    私有子网路由：默认路由 0.0.0.0/0 指向 NAT 网关，而非互联网网关。

  2. 2

    源地址转换：NAT 把数据包源 IP 改为自己的公网 IP，并分配源端口。

  3. 3

    连接跟踪：记录内网地址端口与外网端口的映射，回包据此转发回原主机。

  4. 4

    拒绝入站：没有映射记录的外部主动连接被丢弃，形成单向出站访问。

  5. 5

    出口固定：所有出站流量使用 NAT 的公网 IP，便于第三方配置 IP 白名单。

🔤 03 · 术语
SNAT
源地址转换，改写出站包的源 IP，用于共享公网地址出网。
私有子网 (Private Subnet)
路由表中没有直接指向互联网网关的子网。
弹性公网 IP (Elastic IP)
可固定分配给 NAT 网关的静态公网地址。
端口耗尽 (Port Exhaustion)
到同一目标的并发连接过多，可用源端口不足导致连接失败。
VPC 端点 (VPC Endpoint)
私网直连云服务的通道，不经 NAT 和公网。
💻 04 · 代码
AWS 创建 NAT 网关bash
# 1) 申请一个弹性公网 IP
aws ec2 allocate-address --domain vpc
# → 记下 AllocationId，例如 eipalloc-0abc...

# 2) 在「公有子网」中创建 NAT 网关
aws ec2 create-nat-gateway \
  --subnet-id subnet-0public123 \
  --allocation-id eipalloc-0abc123

# 3) 私有子网路由表：默认路由指向 NAT 网关
aws ec2 create-route \
  --route-table-id rtb-0private456 \
  --destination-cidr-block 0.0.0.0/0 \
  --nat-gateway-id nat-0def789

# Linux 自建 NAT 的等价规则（需开启 ip_forward）：
# iptables -t nat -A POSTROUTING -s 10.0.1.0/24 -o eth0 -j MASQUERADE

NAT 网关放公有子网，私有子网的默认路由指向它；ID 为示例占位。

📊 05 · 参数对比

出网方案对比

方案入站可达典型用途
公网 IP 直连是需对外提供服务的主机
NAT 网关否私有服务器出网拉包、调 API
VPC 端点不涉及公网访问对象存储等云服务
出站代理否需要按域名审计和过滤出站流量
⚖️ 06 · 方案取舍

托管 NAT 网关

优点高可用、免运维、自动扩展

代价按小时+按 GB 计费，流量大时昂贵

适用大多数生产 VPC

自建 NAT 实例

优点成本可控，可自定义规则

代价需自己做高可用与补丁

适用流量大且预算敏感

VPC 端点替代

优点省 NAT 流量费，流量不出公网

代价只覆盖支持的云服务

适用大量访问对象存储等服务

🕳️ 07 · 常见坑

  • ✗只在一个可用区建 NAT，该区故障时所有私有子网断网

    ✓每个可用区各建一个 NAT，路由指向本区 NAT

  • ✗大量流量访问对象存储也走 NAT，费用暴涨

    ✓为对象存储等服务配置 VPC 端点

  • ✗高并发访问同一外部 API 时出现连接失败

    ✓复用长连接/连接池，或增加 NAT 公网 IP 分散端口

  • ✗以为 NAT 等同于防火墙，忽略安全组配置

    ✓NAT 只阻止未请求的入站，仍需安全组与出站策略

🎤 09 · 面试追问
NAT 网关和互联网网关有什么区别？

互联网网关为拥有公网 IP 的实例提供双向互联网访问；NAT 网关让只有私网 IP 的实例共享公网地址主动出站，不接受外部主动发起的入站连接。NAT 网关本身部署在公有子网并经互联网网关出网。

为什么会出现 NAT 端口耗尽？

NAT 用源 IP+源端口区分连接，到同一目标 IP 和端口时可用的源端口有限。大量短连接或不复用连接会迅速占满，加上 TIME_WAIT 延迟释放。解决：连接复用、增加 NAT IP、分散目标。

怎么降低 NAT 网关费用？

先看流量去向：访问对象存储、容器镜像仓库等云服务改走 VPC 端点；镜像与依赖使用私有仓库缓存；避免跨可用区访问 NAT 产生额外流量费；非生产环境评估自建 NAT 实例。
