思考预算 (Reasoning Effort)

Reasoning Effort / Thinking Budget

🧸 回到小白版
📐定义⚙️原理🔤术语💻代码📊参数对比⚖️方案取舍🕳️常见坑☑️检查清单🎤面试追问🔗延伸阅读
📐 01 · 定义

思考预算（Reasoning Effort / Thinking Budget）是推理模型的 API 参数，控制模型给出答案前生成多少内部推理 Token。OpenAI 用档位（如 low/medium/high），Anthropic 用 budget_tokens，Gemini 也有 thinking budget。它是在质量、延迟与成本之间调节的推理层旋钮。

⚙️ 02 · 原理
  1. 1

    推理模型在输出答案前先生成思考内容（可能隐藏、摘要或部分可见），用于分解问题、尝试与自检。

  2. 2

    档位或预算限制思考 Token 的数量上限或倾向；预算越高，复杂任务上通常越准，但延迟与费用上升。

  3. 3

    思考 Token 计入输出 Token 计费，并占用 max_tokens 等输出额度。

  4. 4

    模型不一定用满预算：简单问题即使设高档也可能很快结束。

  5. 5

    应用层可按任务难度路由档位，或先低档尝试、失败后升档重试。

🔤 03 · 术语
推理 Token (Reasoning Tokens)
模型内部思考产生的 Token，按输出计费。
reasoning effort
OpenAI 推理模型的档位参数，控制推理投入程度。
budget_tokens
Anthropic 扩展思考的预算参数，须小于 max_tokens。
测试时计算 (Test-time Compute)
推理阶段投入更多计算以换取更好结果的思路。
交错思考 (Interleaved Thinking)
在工具调用之间穿插思考，部分模型支持。
💻 04 · 代码
两家 API 设置思考预算python
# pip install openai anthropic
from openai import OpenAI
import anthropic

# OpenAI Responses API：用档位控制
oa = OpenAI()
r = oa.responses.create(
    model="o4-mini",                 # 换成你在用的推理模型
    reasoning={"effort": "low"},     # 简单任务用低档
    input="把 'hello world' 转成驼峰命名",
)
print(r.output_text)
print("推理 tokens:", r.usage.output_tokens_details.reasoning_tokens)

# Anthropic：用 budget_tokens 控制扩展思考
an = anthropic.Anthropic()
m = an.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=16000,                               # 必须大于思考预算
    thinking={"type": "enabled", "budget_tokens": 8000},
    messages=[{"role": "user", "content": "分析这段并发代码可能的死锁原因…"}],
)
for b in m.content:
    print(b.type)   # 先出现 thinking 块，再出现 text 块

参数名与取值因厂商和模型而异，以所用模型文档为准；思考 Token 同样计费。

⚖️ 06 · 方案取舍

低档/小预算

优点快、便宜

代价复杂任务准确率下降

适用格式转换、简单问答、高并发

高档/大预算

优点复杂推理更可靠

代价延迟高、费用高

适用疑难调试、数学、架构设计

按难度动态路由

优点整体性价比最好

代价需要分类器或升档逻辑

适用任务难度分布广的产品

🕳️ 07 · 常见坑

  • ✗所有请求一律最高档

    ✓按任务评测各档位的准确率与成本，选拐点

  • ✗max_tokens 不足，思考耗尽额度导致无回答

    ✓为思考与最终回答都预留输出空间

  • ✗把思考内容当作可靠解释直接展示给用户

    ✓思考内容不保证忠实于真实计算过程，只展示最终答案或摘要

  • ✗对交互式场景开高档，用户等待过久

    ✓交互用低档并流式输出，后台任务再用高档

☑️ 08 · 检查清单
🎤 09 · 面试追问
思考预算和 max_tokens 的关系？

思考 Token 属于输出，占用输出额度并计费。Anthropic 要求 budget_tokens 小于 max_tokens；OpenAI 推理模型应通过 max_completion_tokens/max_output_tokens 为推理与回答共同留足空间，否则可能推理用尽额度而无可见回答。

如何为产品选择默认档位？

用代表性任务集在各档位上测准确率、延迟与成本，找收益拐点；交互式路径偏低档，离线或高价值任务偏高档；再用路由或失败升档机制处理难例，并持续监控。

为什么更多思考不一定更好？

简单任务上收益饱和，只增加延迟与费用；过度思考可能偏离或产生过度复杂的方案；有研究报告在某些任务上更长推理反而降低准确率。应以评测数据为准。
