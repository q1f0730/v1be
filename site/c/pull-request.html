🎯 一句话

🧸 打个比方

PR 像交作业给老师批改。老师看过点头了。作业才算数。

  • 📤 分支做完后发起 PR
  • 👀 别人或 AI 先审查代码
  • ✅ 审过了才合进主线

📊 ✅好PR vs ❌坏PR

对比✅ 好 PR❌ 坏 PR
大小只改一件事一次改一百处
说明写清改了啥空白

  3. 3

    🤖 让 AI 先帮你审一遍

💥 翻车现场

一个 PR 改了两千行，没人看得完，Bug 混进了线上。

🤖 复制给 AI 的话

请帮我把当前分支发起一个 PR，写清改了什么、为什么改、怎么测试，并先自己审查一遍。
