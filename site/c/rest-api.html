🎯 一句话

一套大家都认的接口写法规矩

🧸 打个比方

像餐厅点菜的统一规矩。看菜单、下单、退单，各有固定说法。服务员一听就懂。

  • 🧭 网址代表东西，如 /users 是用户
  • 🔤 用不同动作：查、建、改、删
  • 📦 返回的数据一般是 JSON 格式

📊 REST 常用动作

动作干什么生活类比

POST新建数据下单

💥 翻车现场

接口全叫 /doThing1、/doThing2。三个月后，自己都不知道哪个干嘛。

🤖 复制给 AI 的话

按 REST 规范帮我设计用户和订单的接口：用名词网址和 GET/POST/PUT/DELETE，返回 JSON，并列出接口清单。

✅ 小测一下

REST 风格里，网址通常代表什么？

💡 REST 用网址表示资源，用 GET、POST 表示动作。
