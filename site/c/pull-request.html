合并请求 (PR)

Pull Request

🎓 专业模式
🎯一句话🧸打个比方🎬动起来看📊对比表👣怎么做💥翻车现场🤖给 AI 的话✅小测一下📚词汇
🎯 01 · 一句话

请求把你的改动合进主线

🧸 02 · 打个比方

PR 像交作业给老师批改。老师看过点头了。作业才算数。

  • 📤 分支做完后发起 PR
  • 👀 别人或 AI 先审查代码
  • ✅ 审过了才合进主线
🎬 03 · 动起来看
📤提交PR
👀审查
🛠️修改

👀 改到通过为止

📊 04 · 对比表

✅好PR vs ❌坏PR

对比✅ 好 PR❌ 坏 PR
大小只改一件事一次改一百处
说明写清改了啥空白
测试附上测试结果没测过
👣 05 · 怎么做
  1. 1

    🌿 在分支上做完功能

  2. 2

    📝 让 AI 写 PR 说明

  3. 3

    🤖 让 AI 先帮你审一遍

💥 06 · 翻车现场

一个 PR 改了两千行，没人看得完，Bug 混进了线上。

🤖 07 · 给 AI 的话
请帮我把当前分支发起一个 PR，写清改了什么、为什么改、怎么测试，并先自己审查一遍。
✅ 08 · 小测一下

PR 主要用来做什么？

💡 PR 是请别人审查后，把改动合进主线。
