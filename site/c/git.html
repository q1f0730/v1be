🎯 一句话

给代码存档、随时能回退

🧸 打个比方

Git 像游戏存档。打 Boss 前先存一下。打输了就读档重来。

  • 💾 每次存档都记下改了啥
  • ⏪ 改坏了能退回任意版本
  • 🤖 让 AI 改代码前先存档

💥 翻车现场

没用 Git，AI 一次改坏十个文件，好的版本再也找不回。

🤖 复制给 AI 的话

请帮我给这个项目初始化 Git，建好 .gitignore，并做第一次提交，说明写「初始版本」。
