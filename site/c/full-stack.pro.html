📐 01 · 定义

全栈（Full Stack）指覆盖一个应用从界面到数据的全部技术层：前端、后端 API、数据库，以及部署和运维。全栈开发者或全栈框架能独立交付端到端功能。在 AI 编程时代，Agent 让个人更容易跨层开发，但跨层的数据契约、安全边界和部署链路仍需要人理解与把关。

⚙️ 02 · 原理
  1. 1

    表现层：前端负责界面渲染、用户交互与客户端状态管理，运行在浏览器或 App 中。

  2. 2

    接口层：通过 REST、GraphQL 或 RPC 定义前后端之间的数据契约与错误约定。

  3. 3

    业务层：后端实现业务规则、身份鉴权、数据库事务以及支付、模型等第三方集成。

  4. 4

    数据层：数据库存储持久数据，缓存与对象存储辅助性能与文件管理。

  5. 5

    交付层：构建、部署、域名、HTTPS、监控把应用送到用户面前并保持运行。

🔤 03 · 术语
技术栈 (Tech Stack)
一个项目采用的语言、框架、数据库与基础设施组合。
全栈框架 (Meta-framework)
如 Next.js，在一个项目内同时写页面和服务端逻辑。
数据契约 (API Contract)
前后端约定的请求与响应结构，常用 OpenAPI 描述。
端到端类型安全 (E2E Type Safety)
前后端共享类型定义，接口变化在编译期暴露。
CI/CD
持续集成与持续部署，自动测试并发布代码。
💻 04 · 代码
Next.js 同仓前后端typescript
// app/api/hello/route.ts —— 服务端：Route Handler
export async function GET() {
  // 这里可以访问数据库和环境变量中的密钥，代码不会发到浏览器
  return Response.json({ message: "hello from server" });
}

// app/page.tsx —— 前端：React 页面（客户端组件）
"use client";
import { useEffect, useState } from "react";

export default function Home() {
  const [msg, setMsg] = useState("加载中…");
  useEffect(() => {
    fetch("/api/hello")
      .then((r) => r.json())
      .then((d) => setMsg(d.message))
      .catch(() => setMsg("加载失败"));
  }, []);
  return <h1>{msg}</h1>;
}

两个文件分属服务端和浏览器，同在一个仓库；分清代码运行在哪一侧是全栈开发的关键。

🕳️ 07 · 常见坑

  • ✗在同仓库里把服务端密钥误用到客户端代码

    ✓区分服务端与客户端模块，只有明确公开的变量才能暴露

  • ✗前后端各自定义数据结构，改一边忘一边

    ✓共享类型定义或用 OpenAPI 生成客户端

  • ✗本地能跑就算完成，忽视部署环境差异

    ✓尽早部署到预发环境，验证环境变量、数据库与构建

🎤 09 · 面试追问
全栈开发者应该「样样精通」吗？

通常是「T 型」：对一层有深度，对其他层有足够理解，能打通端到端流程并知道何时求助专家。关键能力是理解层与层之间的契约：数据如何流动、在哪里鉴权、出错如何传递。

Next.js 中客户端组件和服务端组件的区别？

服务端组件只在服务器渲染，可直接访问数据库和密钥，不把代码发给浏览器；客户端组件用「use client」声明，会下发到浏览器，可使用状态和事件。错误放置会导致密钥泄露或功能失效。

AI 帮你写全栈应用，你最该亲自把关哪里？

跨层边界：鉴权在哪一层执行、数据库访问权限、哪些变量暴露给客户端、接口输入校验、部署配置与密钥管理。单层代码 AI 写得不错，跨层安全边界最易出错且后果最重。
