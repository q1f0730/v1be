增删改查 (CRUD)

CRUD

  1. 🎯
  2. 🧸

  4. 📊
  5. 👣
  6. 💥
  7. 🤖

🎯 一句话

数据的四种基本操作：增、查、改、删。

🧸 打个比方

像管理手机通讯录。加个新朋友，找个电话，改个备注，删个旧号。

  • ➕ Create 增：新建一条数据。
  • 🔍 Read 查：读出数据看看。
  • ✏️ Update 改，Delete 删。

🎬 动起来看

➕增加
🔍查询
✏️修改
🗑️删除

👀 几乎所有应用都在做这四件事

📊 CRUD 对照表

操作生活里网页上的按钮
增 Create加新联系人发布
查 Read找电话搜索
改 / 删改备注或删号编辑 / 删除

💥 翻车现场

做了删除功能，忘了确认弹窗。用户手一滑，一年的笔记全没了。

🤖 复制给 AI 的话

请为“笔记”做完整的增删改查接口和页面。删除前要弹窗确认，每个操作都校验是不是本人的笔记。

✅ 小测一下

“修改个人资料”属于 CRUD 哪个？

💡 改已有的数据，就是 Update。
