🎯 一句话

包在模型外面、让它能干活的那套壳

🧸 打个比方

模型像发动机，外壳像整辆车。有方向盘、刹车、油箱。发动机才能真上路。

  • 🧠 模型只会“想”和“说”
  • 🧰 外壳给它工具、记忆和规则
  • 🚗 Claude Code 就是一种外壳
