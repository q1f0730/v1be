🎯 一句话

程序之间传数据的通用格式

🧸 打个比方

JSON 像快递单。姓名、电话、地址，各填一格。谁拿到都看得懂。

  • 🏷️ 每条数据都是「名字: 值」
  • 🧩 用大括号 {} 把数据包起来
  • 🤖 AI 和 API 最爱用它传数据

📊 ✅ 对 vs ❌ 错

写法对不对原因
"age": 18✅ 对名字加双引号
age: 18❌ 错名字没引号
结尾多个逗号❌ 错最后一项不加逗号
