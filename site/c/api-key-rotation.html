🎯 一句话

定期换新密钥，旧的作废。

🧸 打个比方

金库每 30 天换一次锁芯。小偷上月偷拍的钥匙，今天就插不进了。

  • 🔑 密钥用久了，泄露的风险越来越大。
  • 🔄 定期换新，旧的就没用了。
  • 🤝 换的时候新旧并存一小会，不掉线。

🎬 动起来看

🔑
API 密钥⏳ 30 天一换⌛ 时间到 → 失效

👀 到期换新，旧钥匙作废

📊 定期换 vs 从不换

对比项✅ 定期换❌ 从不换
泄露后很快失效永久能用
换的时候新旧并存服务中断
存放位置机密管理写在代码里

👣 你该怎么做

  1. 1

    📅 给每个密钥记下创建日期。

  2. 2

    🔄 到期就去后台生成新的。

  3. 3

    🗑️ 新的生效后，删除旧密钥。

💥 翻车现场

三年前的密钥一直没换。前员工离职还能用，账单多出几万块。

🤖 复制给 AI 的话

请设计支持新旧两个 API 密钥同时有效的校验逻辑，方便定期轮换。旧密钥在切换完成后作废。

✅ 小测一下

为什么要定期换密钥？

💡 定期轮换缩短了泄露密钥能用的时间。
