系统提示词

System Prompt

🧸 回到小白版
📐定义⚙️原理🔤术语💻代码📊参数对比⚖️方案取舍🕳️常见坑☑️检查清单🎤面试追问🔗延伸阅读
📐 01 · 定义

系统提示词（System Prompt）是在对话开始前设定、通常对终端用户不可见的高优先级指令，用来定义模型的角色、行为边界、输出风格和可用工具规则。它在 API 中以独立的 system 字段或 system 角色传入，是产品方塑造模型行为的主要手段，每次请求都会随之发送。

⚙️ 02 · 原理
  1. 1

    传入：API 调用时通过 system 参数（Anthropic）或 system/developer 角色消息（OpenAI）传入。

  2. 2

    置顶：系统提示位于上下文最前端，模型训练时被教导更优先遵守这一层指令。

  3. 3

    常驻：每轮请求都会重复发送，因此会持续占用 Token，可配合提示缓存降低成本。

  4. 4

    分层：产品方系统提示 > 用户消息 > 工具返回内容，冲突时模型通常倾向更高层。

  5. 5

    组合：Agent 框架常把角色、工具说明、项目规则（如 CLAUDE.md）拼装进系统提示。

🔤 03 · 术语
指令层级 (Instruction Hierarchy)
系统、开发者、用户、工具内容的优先级顺序。
Developer Message
OpenAI 新接口中替代 system 的开发者指令角色。
护栏 (Guardrails)
限制模型能做什么、不能说什么的规则与检测机制。
提示泄露 (Prompt Leaking)
用户诱导模型复述系统提示，暴露内部规则。
项目记忆文件 (CLAUDE.md / AGENTS.md)
编码 Agent 自动读入的项目级说明，作用类似系统提示。
💻 04 · 代码
设置系统提示python
import anthropic

client = anthropic.Anthropic()

SYSTEM = """你是某 SaaS 产品的技术支持助手。
- 只回答与本产品相关的问题，其他问题礼貌拒绝。
- 不确定时说「我需要确认」，不要编造功能。
- 回答用简体中文，先给结论，再给步骤。"""

resp = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=400,
    system=SYSTEM,               # Anthropic：独立的 system 参数
    messages=[{"role": "user", "content": "怎么导出数据？"}],
)
print(resp.content[0].text)

# OpenAI Chat Completions 写法：
# messages=[{"role": "system", "content": SYSTEM},
#           {"role": "user", "content": "怎么导出数据？"}]

两家接口放置位置不同，但作用一致：在用户消息之前设定角色和规则。

⚖️ 06 · 方案取舍

规则写在系统提示

优点每轮生效，优先级高

代价常驻占 Token，过长会稀释重点

适用全局稳定的角色和规则

规则写在用户消息

优点灵活、按需注入

代价优先级低，可能被后续对话冲淡

适用单次任务的临时要求

规则用代码强制

优点确定性，不依赖模型自觉

代价开发成本高，覆盖面有限

适用安全、权限、合规类硬约束

🕳️ 07 · 常见坑

  • ✗把密钥或内部机密写进系统提示

    ✓系统提示可能被诱导泄露，机密留在后端代码里

  • ✗系统提示越写越长，规则互相矛盾

    ✓定期精简，按优先级排序，删掉过时规则

  • ✗把安全边界完全交给系统提示

    ✓权限和危险操作在工具层用代码拦截

  • ✗改了系统提示不做回归

    ✓像改代码一样版本化并跑评测样本

🎤 09 · 面试追问
系统提示能防止越狱吗？

只能提高门槛，不能保证。模型对指令层级的遵守是概率性的。可靠的做法是纵深防御：系统提示声明边界、输入输出检测、工具最小权限、敏感操作人工确认，把真正不可越过的边界放在代码层。

CLAUDE.md 和系统提示是什么关系？

Claude Code 会在会话开始时读取项目中的 CLAUDE.md 并注入上下文，作用类似项目级系统提示：记录构建命令、代码规范、目录约定。区别是它由仓库维护，团队共享，随代码一起版本化。Cursor 规则文件、AGENTS.md 思路相同。

系统提示很长，如何控制成本？

使用提示缓存：把系统提示和工具定义等稳定前缀放在最前并标记缓存，后续命中时输入成本和延迟显著下降。同时精简措辞、把很少用到的规则改为按需检索注入。
