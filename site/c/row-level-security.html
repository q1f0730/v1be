🎯 一句话

数据库自己保证：每人只能看自己的行

🧸 打个比方

几家公司共用一本账。A 公司的人翻开，只看到自己那几行。别人的自动隐形。

  • 🧱 规则写在数据库里，不靠代码
  • 😅 不怕忘写过滤条件
  • ⚡ 用 Supabase 时一定要开

📊 开不开 RLS

场景没开 RLS开了 RLS
忘写过滤条件全表泄露只看自己

新人写新接口容易出错有兜底

💥 翻车现场

Supabase 表忘了开 RLS，有人用公开 key 一查，全部用户的数据都下载走了。

🤖 复制给 AI 的话

请检查 Supabase 里所有表是否开启 Row-Level Security，并为每张表写策略：用户只能读写 user_id 等于自己的行。
