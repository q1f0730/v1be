旋转位置编码与长上下文扩展

RoPE & Context Extension

🧸 回到小白版

📐 01 · 定义

旋转位置编码（RoPE，Su 等 2021 年提出于 RoFormer）把位置信息编码为对查询和键向量的旋转：向量的每对维度按位置乘以不同频率的角度旋转，使注意力点积只依赖两个 Token 的相对距离。它是当前主流开源 LLM 的位置编码方式。在此基础上，位置插值、NTK 缩放、YaRN 等方法可以让模型以少量或无需额外训练扩展上下文长度。

⚙️ 02 · 原理
  1. 1

    把查询/键向量的维度两两配对，第 i 对使用频率 θ_i = base^(−2i/d)，原始 base 为 10000。

  2. 2

    位置 m 的 Token 将第 i 对维度旋转角度 m·θ_i；高频维度编码近距离细节，低频维度编码远距离关系。

  3. 3

    两个旋转后向量的点积只与位置差 m−n 有关，因此注意力天然具有相对位置性质。

  4. 4

    超出训练长度时会出现未见过的旋转角度，模型表现骤降；位置插值把位置按比例压缩回训练范围。

  5. 5

    NTK 感知缩放通过增大 base 主要拉伸低频维度；YaRN 按频率分段插值并调整注意力温度，常配合少量长文本继续训练。

🔤 03 · 术语
RoPE base (rope_theta)
决定旋转频率范围的超参数，增大它可以支持更长的位置。
位置插值 (Position Interpolation)
把超长位置线性缩放到训练长度范围内再计算旋转。
YaRN
按频率分段处理的 RoPE 扩展方法，兼顾高频细节与长距离外推。
有效上下文 (Effective Context)
模型在该长度下仍能可靠完成检索与推理的实际长度，常小于标称值。
RULER
NVIDIA 提出的长上下文评测基准，测量模型的真实有效上下文长度。
💻 04 · 代码
RoPE 的相对位置性质python
import numpy as np

def rope(x, pos, base=10000.0):
    """对向量 x（维度为偶数）施加位置 pos 的旋转"""
    d = x.shape[-1]
    theta = base ** (-np.arange(0, d, 2) / d)       # 每对维度的频率
    ang = pos * theta
    x1, x2 = x[0::2], x[1::2]
    out = np.empty_like(x)
    out[0::2] = x1 * np.cos(ang) - x2 * np.sin(ang)
    out[1::2] = x1 * np.sin(ang) + x2 * np.cos(ang)
    return out

rng = np.random.default_rng(0)
q, k = rng.standard_normal(64), rng.standard_normal(64)

# 位置 (10, 3) 与 (1007, 1000) 的相对距离都是 7
s1 = rope(q, 10) @ rope(k, 3)
s2 = rope(q, 1007) @ rope(k, 1000)
print(np.isclose(s1, s2))     # True：点积只取决于相对距离

# Hugging Face 配置中启用 YaRN 的常见写法（具体以模型官方文档为准）：
# "rope_scaling": {"type": "yarn", "factor": 4.0,
#                  "original_max_position_embeddings": 32768}

相对位置性质让 RoPE 可以通过调整频率或缩放位置来扩展长度；能否真正用好长上下文仍需评测。

⚖️ 06 · 方案取舍

使用模型原生长上下文

优点无需额外工程，官方已评测

代价长输入成本与延迟高

适用确实需要整体理解长文档

推理时开启 RoPE 缩放

优点配置即可扩展长度

代价可能影响短文本表现，需验证

适用官方明确支持该缩放方式时

检索与分块（RAG）

优点只送相关内容，便宜且可追溯

代价可能漏检跨段信息

适用知识库问答、文档量远超窗口

🕳️ 07 · 常见坑

  • ✗把标称上下文长度当作有效长度

    ✓用 RULER 或自建的大海捞针任务实测有效长度

  • ✗随意修改 rope_scaling 而不评测

    ✓按官方推荐配置，并在短、长两类任务上回归评测

  • ✗长上下文中关键信息放在中间

    ✓把指令和关键材料放在开头或结尾，必要时重复要点

  • ✗忽视长上下文的 KV 缓存与成本

    ✓估算显存与费用，优先裁剪无关内容或使用缓存

🎤 09 · 面试追问
RoPE 为什么能编码相对位置？

位置 m 的向量被旋转 m·θ 角，位置 n 的被旋转 n·θ 角。二维旋转矩阵满足 R(m)ᵀR(n)=R(n−m)，所以两者点积等于原向量经 R(n−m) 作用后的点积，只取决于相对距离。多组频率叠加，使模型同时感知近距离与远距离关系。

位置插值与 NTK 缩放的区别？

位置插值把所有位置按同一比例压缩，所有频率同等变慢，近距离分辨率下降；NTK 感知缩放增大 base，主要放慢低频维度、基本保留高频维度，对短距离细节影响更小。YaRN 进一步按频段区别处理，并修正注意力熵。

百万 Token 上下文能替代 RAG 吗？

不完全能。长上下文适合需要整体理解的少量长文档，但成本与延迟随长度增长，模型对中间位置信息的利用也不稳定；RAG 便宜、可更新、可引用来源。实践中常组合：检索缩小范围，再在较长上下文中综合推理。
