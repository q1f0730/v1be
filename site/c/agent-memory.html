🎯 一句话

让 AI 记住你和项目，下次不用重说

🧸 打个比方

常去的奶茶店，店员记得你要少糖。你不用每次再说。这就是记忆。

  • 🗂️ 短期记忆：这次对话里的内容
  • 📒 长期记忆：存在文件或数据库里
  • 🧹 记错的东西要能改、能删

💥 翻车现场

你说过一次“用中文注释”，AI 记成了全局规则，连英文项目也写满中文。
