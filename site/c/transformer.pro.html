📐 01 · 定义

Transformer 是 2017 年论文《Attention Is All You Need》提出的神经网络架构，用自注意力（Self-Attention）替代循环结构来建模序列中任意位置间的依赖。它由嵌入、位置编码和若干堆叠的注意力 + 前馈网络块组成，可高度并行训练，是 GPT、Claude、Llama 等主流大语言模型的共同骨架。

⚙️ 02 · 原理
  1. 1

    分词器把文本切成 token，每个 token 映射为向量（嵌入），再注入位置信息（原论文为正弦位置编码，现代模型多用 RoPE 等）。

  2. 2

    每个 Transformer 块先做多头自注意力，让每个位置按相关性聚合其他位置的信息，再经过逐位置的前馈网络（FFN）。

  3. 3

    每个子层外包残差连接和层归一化，使几十上百层的深网络能稳定训练；现代 LLM 多采用 Pre-LN 结构。

  4. 4

    仅解码器（decoder-only）模型使用因果掩码，每个位置只能看到之前的 token，以“预测下一个 token”为训练目标。

  5. 5

    最后一层输出经线性层与 softmax 得到词表概率分布，按采样策略选出下一个 token，追加后重复，直到结束。

🔤 03 · 术语
自注意力 (Self-Attention)
序列内部每个位置对所有位置计算相关权重并加权求和。
前馈网络 (FFN / MLP)
注意力后逐位置的两层全连接网络，占据大部分参数。
残差连接 (Residual Connection)
把子层输入直接加到输出上，缓解深层网络梯度问题。
仅解码器 (Decoder-only)
只保留带因果掩码的解码器堆叠，GPT 系列等 LLM 采用。
位置编码 (Positional Encoding)
为无序的注意力注入 token 顺序信息，如正弦编码、RoPE。
因果掩码 (Causal Mask)
屏蔽未来位置，保证生成时只依赖已出现的 token。
💻 04 · 代码
PyTorch 搭一个最小编码器python
import torch
import torch.nn as nn

d_model, n_head, n_layer = 512, 8, 6   # 原论文 base 配置
layer = nn.TransformerEncoderLayer(
    d_model=d_model, nhead=n_head,
    dim_feedforward=2048, batch_first=True,
    norm_first=True,          # Pre-LN，现代模型常用
)
encoder = nn.TransformerEncoder(layer, num_layers=n_layer)

x = torch.randn(2, 10, d_model)      # (batch, 序列长度, 维度)
# 因果掩码：上三角为 True 表示不可见
mask = nn.Transformer.generate_square_subsequent_mask(10).bool()
y = encoder(x, mask=mask, is_causal=True)
print(y.shape)                         # torch.Size([2, 10, 512])

用 PyTorch 内置模块堆叠 6 层注意力+FFN 块，并加因果掩码模拟解码器式的单向可见性。

⚖️ 06 · 方案取舍

Transformer（稠密）

优点并行训练、长程依赖建模好

代价注意力计算随序列长度平方增长

适用通用 LLM 的默认选择

混合专家 MoE

优点参数量大但每 token 只激活部分专家

代价显存占用大、路由训练复杂

适用追求大容量又要控制推理计算

RNN / 状态空间模型

优点推理时每步成本与长度无关

代价并行训练难或生态较小

适用超长序列或流式场景研究

🕳️ 07 · 常见坑

  • ✗把“层数多”等同于“模型强”

    ✓能力取决于参数、数据量与训练计算的平衡，盲目加深难以训练且收益有限

  • ✗以为模型能看见“字”

    ✓模型只看到 token 序列，拼写、数字位数等问题常源于分词

  • ✗认为上下文窗口内信息被同等利用

    ✓注意力分配不均，长上下文中段信息常被弱化，关键内容应放首尾

  • ✗把 Transformer 和“会推理”画等号

    ✓架构只决定计算方式，推理能力来自训练数据与后训练方法

🎤 09 · 面试追问
Transformer 为什么比 RNN 训练快？

RNN 必须按时间步顺序计算，第 t 步依赖第 t-1 步的隐藏状态，无法在序列维度并行。Transformer 用注意力一次性计算所有位置间的关系，训练时整段序列可在 GPU 上并行矩阵运算，因而能扩展到更大数据和模型。

为什么需要位置编码？

自注意力对输入顺序是置换等变的：打乱 token 顺序，每个位置的计算结果只是跟着重排。不注入位置信息，模型无法区分“狗咬人”和“人咬狗”。因此要加绝对位置编码或 RoPE 等相对位置方案。

FFN 在 Transformer 中起什么作用？

注意力负责在位置之间搬运信息，FFN 负责在每个位置内做非线性变换，被认为存储了大量知识。FFN 隐藏层通常是模型维度的数倍（原论文为 4 倍），参数量占比最大，MoE 正是把 FFN 拆成多个专家。
