数值精度 (FP32 / BF16 / FP8)

Numeric Precision

📐 01 · 定义

数值精度（Numeric Precision）指模型权重、激活和梯度用何种数据格式表示，如 FP32、FP16、BF16、FP8 及整数格式。它属于训练与推理的数值计算层，直接决定显存占用（每参数 4/2/1 字节）、计算吞吐（新硬件对低精度有专用 Tensor Core 加速）和数值稳定性。混合精度训练与低精度推理是当前主流。

⚙️ 02 · 原理
  1. 1

    浮点数由符号位、指数位和尾数位组成：指数位决定可表示的范围，尾数位决定精度。

  2. 2

    FP16（1-5-10）精度较高但范围小，训练时需损失缩放防止梯度下溢；BF16（1-8-7）与 FP32 范围相同，精度较低，更稳定。

  3. 3

    FP8 有 E4M3（精度优先）与 E5M2（范围优先）两种格式，需配合缩放因子，并需 Hopper、Ada 等较新架构的硬件支持。

  4. 4

    混合精度训练用低精度做前向与反向计算，保留 FP32 主权重与累加，兼顾速度与稳定性。

  5. 5

    推理时常以 BF16/FP16 加载，进一步用 FP8 或 INT8/INT4 量化以降低显存与带宽需求。

🔤 03 · 术语
指数位 / 尾数位 (Exponent / Mantissa)
分别决定数值范围和有效精度。
BF16 (bfloat16)
保留 FP32 的 8 位指数，尾数 7 位，训练稳定。
FP8 (E4M3 / E5M2)
8 位浮点格式，需缩放因子，用于训练与推理加速。
混合精度 (Mixed Precision)
低精度计算 + 高精度主权重/累加的组合方案。
损失缩放 (Loss Scaling)
放大损失以避免 FP16 梯度下溢，再缩回更新。
TF32
NVIDIA Ampere 起的矩阵运算格式，FP32 范围、10 位尾数。
💻 04 · 代码
PyTorch 混合精度与显存估算python
import torch

# 各精度每个元素的字节数
for dt in (torch.float32, torch.float16, torch.bfloat16):
    print(dt, torch.tensor([], dtype=dt).element_size(), "bytes")

# 7B 参数模型仅权重所需显存（不含 KV 缓存与激活）
params = 7e9
for name, b in {"FP32": 4, "BF16": 2, "FP8/INT8": 1, "INT4": 0.5}.items():
    print(f"{name:8s} ≈ {params * b / 1024**3:.1f} GiB")

# 混合精度训练：autocast 内用 BF16 计算，参数仍为 FP32
model = torch.nn.Linear(1024, 1024).cuda()
opt = torch.optim.AdamW(model.parameters())
x = torch.randn(8, 1024, device="cuda")
with torch.autocast(device_type="cuda", dtype=torch.bfloat16):
    loss = model(x).float().pow(2).mean()
loss.backward()   # BF16 范围与 FP32 相同，通常无需 GradScaler
opt.step()

权重显存与字节数成正比；BF16 autocast 是常用的混合精度方式（需支持 BF16 的 GPU）。

⚖️ 06 · 方案取舍

BF16

优点稳定、无需损失缩放、生态成熟

代价精度低于 FP16，老 GPU 不支持

适用Ampere 及更新 GPU 的训练与推理

FP16

优点旧硬件广泛支持

代价范围小，易溢出，训练需损失缩放

适用不支持 BF16 的设备

FP8

优点吞吐更高、显存减半（相对 BF16）

代价需硬件支持与缩放校准

适用Hopper/Ada 及更新硬件的大规模部署

INT4 等低比特量化

优点显存最小，可在消费级设备运行

代价质量损失需评估

适用本地与边缘推理

🕳️ 07 · 常见坑

  • ✗在不支持 BF16 的 GPU 上强行使用 BF16

    ✓先确认硬件能力（torch.cuda.is_bf16_supported()），否则用 FP16

  • ✗FP16 训练不做损失缩放，梯度变成 0 或 NaN

    ✓使用 GradScaler 等动态损失缩放

  • ✗把累加和归一化也放在低精度

    ✓softmax、LayerNorm、累加保持 FP32，框架 autocast 通常会处理

  • ✗只按权重估显存，忽略优化器状态

    ✓训练时 AdamW 状态和主权重通常是权重显存的数倍

☑️ 08 · 检查清单
🎤 09 · 面试追问
BF16 为什么比 FP16 更适合训练？

BF16 与 FP32 指数位相同，可表示范围一致，梯度和激活不易溢出或下溢，通常无需损失缩放；虽然尾数精度更低，但深度学习对此较不敏感。

FP8 训练的关键难点？

动态范围和精度都很有限，需要按张量或按块的缩放因子，并在前向用 E4M3、反向梯度常用 E5M2；敏感算子保持高精度，并依赖硬件 Tensor Core 支持。

精度和量化是一回事吗？

相关但不同。精度指数据格式；量化通常指把高精度权重映射到低比特（尤其整数）表示并配合缩放因子，是降低精度的一类具体方法，常伴随校准过程。
