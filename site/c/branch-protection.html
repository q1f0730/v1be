🎯 一句话

给主分支上锁，改它必须走审查

🧸 打个比方

法典母本放在玻璃柜里。想改一个字，要法官签字。还要过安检才行。

  • 🌳 主分支 main 就是线上用的代码
  • 👀 合并前必须有人审过
  • 🤖 自动测试不过，按钮是灰的

🎬 动起来看

📝提交PR
🔎审查+测试
🌳合并主分支

👀 不过审查，进不了主分支

📊 开不开保护的区别

场景没保护有保护
有人强推代码直接覆盖被拦下
测试没通过照样合并不让合并
没人审过随便上线必须审批

👣 你该怎么做

  1. 1

    ⚙️ 打开 GitHub 仓库的设置页

  2. 2

    🛡️ 给 main 加一条分支保护规则

  3. 3

    ✅ 勾选：要求 PR 审查和测试通过

💥 翻车现场

实习生直接往 main 强推了没测过的代码，安全扫描也绕过了，线上服务当场崩溃。

🤖 复制给 AI 的话
