云网络出站流量费

Egress Fees

📐 01 · 定义

出站流量费（Egress Fees）是云厂商对数据从其网络流出时按量收取的费用，包括流向公网、跨区域、部分情况下跨可用区的传输。入站流量通常免费。它在架构图上不显眼，却常是账单中增长最快、最难预测的一项，也是迁移出云的重要成本壁垒。

⚙️ 02 · 原理
  1. 1

    云厂商按流量方向和目的地分别计价：流入通常免费，流出到公网按 GB 阶梯计费。

  2. 2

    同一区域内不同可用区之间的传输也可能计费（AWS 等对跨 AZ 流量双向收费）。

  3. 3

    经 NAT 网关访问公网或云服务时，除出站费外还有按 GB 计的数据处理费。

  4. 4

    经 CDN 分发时，用户流量从 CDN 出站按 CDN 价格计，回源流量另计。

  5. 5

    账单按用量类型（usage type）汇总，需要用成本分析工具拆解到具体服务与链路。

🔤 03 · 术语
出站流量 (Data Transfer Out)
从云厂商网络流向外部的数据量。
跨可用区流量 (Inter-AZ Transfer)
同区域不同可用区之间的流量，常按 GB 计费。
NAT 网关数据处理费
流经 NAT 网关的每 GB 额外处理费用。
回源 (Origin Fetch)
CDN 未命中时向源站拉取内容产生的流量。
VPC 端点 (VPC Endpoint)
私网访问云服务，可绕开 NAT 网关。
零出站费存储
如 Cloudflare R2，不对出站流量收费的对象存储。
💻 04 · 代码
找出最贵的流量类型bash
#!/usr/bin/env bash
# 用 AWS Cost Explorer 按用量类型拆分上月费用，筛出流量相关项
aws ce get-cost-and-usage \
  --time-period Start=2026-09-01,End=2026-10-01 \
  --granularity MONTHLY \
  --metrics UnblendedCost UsageQuantity \
  --group-by Type=DIMENSION,Key=USAGE_TYPE \
  --query 'ResultsByTime[0].Groups' --output json \
| jq -r '.[]
    | select(.Keys[0] | test("DataTransfer|NatGateway-Bytes|CloudFront"))
    | [.Keys[0], .Metrics.UsageQuantity.Amount, .Metrics.UnblendedCost.Amount]
    | @tsv' \
| sort -t$'\t' -k3 -gr | head -20

# 常见用量类型含义：
#   *-DataTransfer-Out-Bytes       流向公网
#   *-DataTransfer-Regional-Bytes  同区域跨可用区
#   *-NatGateway-Bytes             NAT 网关数据处理

先定位是公网出站、跨 AZ 还是 NAT 处理费，再决定用 CDN、端点还是同 AZ 部署。

⚖️ 06 · 方案取舍

CDN 分发静态与下载内容

优点降低源站出站与延迟

代价增加 CDN 费用与缓存管理

适用下载、图片、视频流量大

零出站费对象存储

优点出站成本几乎可忽略

代价多云架构、生态与功能差异

适用公网分发大文件

服务同 AZ 部署

优点省跨 AZ 费并降延迟

代价可用性降低

适用非关键或可快速重建的组件

🕳️ 07 · 常见坑

  • ✗私有子网服务经 NAT 网关拉取 S3 大文件

    ✓配置 S3 网关端点，流量不经 NAT

  • ✗多 AZ 部署后服务间调用随机跨 AZ

    ✓启用拓扑感知路由，优先同 AZ

  • ✗日志和监控数据全部发往外部 SaaS

    ✓本地采样、过滤、压缩后再发送

  • ✗架构评审只算计算和存储，不算流量

    ✓按数据流图估算各段流量与单价

🎤 09 · 面试追问
为什么云厂商入站免费、出站收费？

一方面网络传输确有成本；另一方面这是商业策略：数据进来容易、出去昂贵，形成数据引力和迁移壁垒。2024 年起三大云陆续为彻底迁出的客户提供出站费减免，但需申请并满足条件。

NAT 网关费用异常高通常是什么原因？

私有子网中的服务通过 NAT 访问 S3、ECR、DynamoDB 等云服务或拉取大镜像，每 GB 都要付处理费。为这些服务配置网关端点或接口端点，可让流量走私网，绕过 NAT。

设计多区域架构时如何考虑流量费？

跨区域复制、同步调用都会产生流量费。应尽量让请求在区域内闭环，只复制必要数据，压缩并批量传输，异步复制替代同步调用，并在方案评审中按预估流量乘单价算清成本。
