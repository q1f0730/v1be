分布式 SQL 数据库 (NewSQL)

Distributed SQL

🎓 专业模式
🎯一句话🧸打个比方🎬动起来看📊对比表👣怎么做💥翻车现场🤖给 AI 的话✅小测一下📚词汇
🎯 01 · 一句话

能用 SQL，数据又能分散到很多台机器

🧸 02 · 打个比方

像连锁银行。你在哪个网点存取都一样。账却分在全国各地记，总数还对得上。

  • 🧾 用法像普通 SQL 数据库
  • 📈 加机器就能扩容，不用手动分库
  • ⚠️ 跨机器写入，延迟会高一点
