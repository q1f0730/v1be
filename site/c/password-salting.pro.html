密码加盐

Password Salting

🧸 回到小白版

📐 01 · 定义

密码加盐（Password Salting）是在哈希密码前为每个用户生成唯一的随机值（盐，Salt）并与密码一起计算哈希的技术。它属于凭证存储层，使相同密码产生不同哈希，令预计算的彩虹表失效，并迫使攻击者对每个账号单独破解。现代密码哈希算法如 Argon2、bcrypt 已内置加盐。

⚙️ 02 · 原理
  1. 1

    用户注册或改密时，用密码学安全随机数生成器为该用户生成足够长的随机盐。

  2. 2

    把盐和密码一起输入慢哈希函数（Argon2id、bcrypt、scrypt），得到哈希值。

  3. 3

    盐不是秘密，通常与算法参数、哈希值一起编码成一个字符串存入数据库。

  4. 4

    登录时从存储字符串中解析出盐和参数，对输入密码重新计算并以恒定时间比较。

  5. 5

    可选再加“胡椒”（Pepper）：一个存放在数据库之外的全局密钥，数据库单独泄露时提供额外保护。

🔤 03 · 术语
盐 (Salt)
每个密码独有的随机值，公开存储，用于使哈希唯一。
彩虹表 (Rainbow Table)
预先计算的哈希到明文对照表，加盐后失效。
胡椒 (Pepper)
存于数据库外的全局秘密，作为额外防护层。
Argon2id
密码哈希竞赛胜出算法的混合变体，抗 GPU 与侧信道。
工作因子 (Work Factor)
控制哈希计算成本的参数，如 bcrypt 的 cost。
💻 04 · 代码
argon2-cffi 哈希与验证python
# pip install argon2-cffi
from argon2 import PasswordHasher
from argon2.exceptions import VerifyMismatchError

ph = PasswordHasher()          # 默认 Argon2id，自动生成随机盐

h1 = ph.hash("correct horse battery staple")
h2 = ph.hash("correct horse battery staple")
print(h1)          # $argon2id$v=19$m=...,t=...,p=...$<盐>$<哈希>
print(h1 != h2)    # True：相同密码因盐不同而哈希不同

def login(stored_hash: str, password: str) -> bool:
    try:
        ph.verify(stored_hash, password)   # 从字符串中解析盐和参数
    except VerifyMismatchError:
        return False
    if ph.check_needs_rehash(stored_hash):
        pass   # 参数升级后，在此用新参数重新哈希并保存
    return True

print(login(h1, "correct horse battery staple"))  # True

盐与参数编码在同一字符串中，无需单独存储；check_needs_rehash 支持平滑升级参数。

⚖️ 06 · 方案取舍

提高哈希成本参数

优点破解更难

代价登录更耗资源，易被用作 DoS

适用在可接受延迟内尽量调高

增加胡椒

优点数据库单独泄露时多一层保护

代价密钥管理与轮换复杂

适用有密钥管理基础设施时

使用托管认证服务

优点无需自己存密码

代价依赖第三方

适用不想承担密码存储风险

🕳️ 07 · 常见坑

  • ✗所有用户使用同一个固定盐

    ✓每个密码独立生成随机盐

  • ✗盐 + SHA-256 就认为足够

    ✓加盐解决彩虹表，还需慢哈希抵抗暴力破解

  • ✗自己拼接盐和密码手写哈希流程

    ✓使用成熟库的高层 API，自动处理盐与编码

  • ✗使用 bcrypt 时未考虑 72 字节限制

    ✓限制密码长度或改用 Argon2id

🎤 09 · 面试追问
盐为什么可以公开存储？

盐的作用不是保密，而是让每个密码的哈希唯一：攻击者无法用一张预计算表破解所有用户，也无法通过相同哈希发现使用相同密码的用户，必须针对每个用户单独计算。真正的计算成本来自慢哈希本身。

盐和胡椒的区别？

盐每用户不同、与哈希一起存于数据库，用于防预计算和批量破解；胡椒是全局秘密，存放在数据库之外（如密钥管理服务），只有在攻击者仅拿到数据库而没拿到应用密钥时才提供额外保护，代价是增加密钥管理复杂度。

如何为老系统升级密码哈希算法？

在用户下次成功登录时，用明文密码以新算法重新哈希并替换；或者对旧哈希值再套一层新算法立即全量升级，登录时按标识选择验证方式。存储格式中带有算法和参数标识，是平滑迁移的前提。
