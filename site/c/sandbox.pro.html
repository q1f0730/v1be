📐 01 · 定义

沙箱（Sandbox）是把代码执行限制在隔离环境中的安全机制，通过限制文件系统、网络、进程权限和资源用量，使不可信代码即使出错或被恶意利用也无法影响宿主系统。在 AI 场景中，它是让 Agent 执行生成代码、运行命令和安装依赖的必要边界，常见实现有容器、gVisor 和微虚拟机。

⚙️ 02 · 原理
  1. 1

    选择隔离边界：语言级、操作系统级（命名空间 + cgroups）、用户态内核或硬件虚拟化。

  2. 2

    文件系统只挂载工作目录，其余只读或不可见，避免读取宿主密钥与配置。

  3. 3

    网络默认禁用，或仅允许访问白名单域名，防止数据外泄与横向访问。

  4. 4

    降低进程权限：非 root 用户、丢弃 Linux capabilities、禁止提权，并设置系统调用过滤。

  5. 5

    限制 CPU、内存、进程数与运行时长，任务结束后立即销毁整个环境。

🔤 03 · 术语
命名空间 (Namespaces)
Linux 隔离进程视图的机制，如 PID、网络、挂载。
cgroups
限制进程组 CPU、内存等资源用量的内核功能。
seccomp
过滤进程可执行的系统调用。
gVisor
在用户态实现内核接口的容器运行时，减少内核攻击面。
微虚拟机 (MicroVM)
如 Firecracker，启动快的轻量虚拟机，隔离强。
💻 04 · 代码
用 Docker 运行不可信代码bash
# 在受限容器中运行 AI 生成的脚本（bash 数组里可以写注释）
opts=(
  --rm
  --network none                  # 断网，防止外泄
  --read-only                     # 根文件系统只读
  --tmpfs /tmp:rw,size=64m        # 仅提供小块可写临时空间
  -v "$PWD/job:/work:ro"          # 代码只读挂载
  --user 1000:1000                # 非 root
  --cap-drop ALL                  # 丢弃全部 capabilities
  --security-opt no-new-privileges
  --memory 512m --cpus 1          # 资源上限
  --pids-limit 128                # 防 fork 炸弹
)
docker run "${opts[@]}" python:3.12-slim \
  timeout 30 python /work/main.py   # 运行时长上限

# 更强隔离：安装 gVisor 后加 --runtime=runsc

断网、只读、非 root、去权限、限资源和超时叠加使用；普通容器仍共享宿主内核。

📊 05 · 参数对比

隔离方案对比

方案隔离强度启动开销典型用途
普通容器中，共享宿主内核低可信或半可信代码
gVisor 容器较高，拦截系统调用低到中多租户代码执行
微虚拟机高，独立内核中云端 Agent 沙箱
完整虚拟机高高长期隔离环境
⚖️ 06 · 方案取舍

本机直接运行

优点最快，环境完整

代价Agent 误操作可破坏本机

适用仅限只读或低风险命令

容器沙箱

优点轻量、易集成

代价内核漏洞可能逃逸

适用自用或可信度较高的代码

微虚拟机/托管沙箱

优点强隔离，适合多租户

代价成本和集成复杂度更高

适用执行用户或 AI 提交的任意代码

🕳️ 07 · 常见坑

  • ✗把 Docker socket 挂进沙箱容器

    ✓绝不挂载 /var/run/docker.sock，它等同宿主 root 权限

  • ✗沙箱里放了真实云凭证或 SSH 密钥

    ✓沙箱只给最小、短期、可撤销的凭证

  • ✗网络完全放开，生成代码可外传数据

    ✓默认断网，按需白名单放行特定域名

  • ✗以 --privileged 运行以解决权限报错

    ✓定位具体所需权限，单独授予而非全开

🎤 09 · 面试追问
为什么说普通容器不是强安全边界？

容器与宿主共享同一内核，内核漏洞或错误配置（特权模式、危险挂载、过多 capabilities）都可能导致逃逸。多租户执行不可信代码时，应使用 gVisor 或微虚拟机这类隔离更强的方案。

编码 Agent 的沙箱要限制什么？

文件系统限制在项目目录、网络限制到必要的包源与 API、禁止访问宿主凭证、命令有超时与资源上限；并配合权限审批，让删除文件、推送代码等不可逆操作需要确认。

沙箱如何防止数据外泄？

核心是网络出口控制：默认拒绝所有出站连接，只允许访问白名单域名；同时不在沙箱中放置敏感数据与长期凭证，并记录出站请求用于审计。
