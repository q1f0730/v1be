网页三件套 HTML / CSS / JS

HTML / CSS / JavaScript

📐 01 · 定义

HTML、CSS、JavaScript 是浏览器原生支持的三种 Web 技术：HTML 描述内容的结构与语义，CSS 控制样式与布局，JavaScript 实现交互逻辑并操作页面。三者分别对应结构层、表现层、行为层。React 等框架最终都编译为这三者，理解它们是判断 AI 生成前端代码质量的基础。

⚙️ 02 · 原理
  1. 1

    HTML 解析：浏览器解析标签生成 DOM 树，语义标签同时服务于可访问性与 SEO。

  2. 2

    CSS 计算：解析样式表生成 CSSOM，按选择器优先级和层叠规则计算每个元素的最终样式。

  3. 3

    布局与绘制：结合 DOM 与样式计算元素位置尺寸（Flexbox、Grid），再绘制到屏幕。

  4. 4

    JS 执行：脚本在事件循环中运行，监听事件、请求数据、修改 DOM 与样式。

  5. 5

    重新渲染：DOM 或样式变化触发重新布局或重绘，频繁触发会影响性能。

🔤 03 · 术语
语义化 HTML (Semantic HTML)
用 header、nav、button 等表达含义的标签。
层叠与优先级 (Cascade / Specificity)
决定多条 CSS 规则冲突时哪条生效。
盒模型 (Box Model)
内容、内边距、边框、外边距构成元素尺寸。
事件循环 (Event Loop)
JavaScript 单线程调度同步代码与异步回调的机制。
响应式设计 (Responsive Design)
用媒体查询等手段让页面适配不同屏幕。
💻 04 · 代码
三件套最小示例text
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <style>
    .card { max-width: 360px; margin: 2rem auto; padding: 1rem;
            border: 1px solid #ddd; border-radius: 8px; }
    button { padding: .5rem 1rem; }
    @media (max-width: 480px) { .card { margin: 1rem; } }  /* 响应式 */
  </style>
</head>
<body>
  <main class="card">                <!-- 语义化标签 -->
    <h1>计数器</h1>
    <p>已点击 <output id="count">0</output> 次</p>
    <button type="button" id="btn">点我</button>  <!-- 用 button 而非 div -->
  </main>
  <script>
    const btn = document.getElementById("btn");
    const out = document.getElementById("count");
    let n = 0;
    btn.addEventListener("click", () => { out.textContent = ++n; });
  </script>
</body>
</html>

结构、样式、行为各司其职；viewport 标签和语义化按钮是 AI 生成页面时常被遗漏的细节。

🕳️ 07 · 常见坑

  • ✗用 div 加点击事件冒充按钮

    ✓使用 button 元素，自带键盘与读屏支持

  • ✗缺少 viewport meta，手机上页面缩成一小块

    ✓head 中加入 viewport 元标签

  • ✗滥用 !important 解决样式冲突

    ✓理解优先级，降低选择器复杂度或调整层叠顺序

  • ✗图片没有 alt，表单没有 label

    ✓补充 alt 文本与关联的 label，提升可访问性

🎤 09 · 面试追问
CSS 优先级怎么计算？

按选择器类别比较：内联样式 > ID 选择器 > 类、属性、伪类选择器 > 元素、伪元素选择器；同级比较数量，相同时后定义的生效；!important 会覆盖普通声明。现代 CSS 还有 @layer 级联层来管理顺序。

JS 是单线程的，为什么能做异步？

JS 主线程单线程执行，但网络请求、定时器等由浏览器或运行时的其他线程处理，完成后把回调放入任务队列；事件循环在调用栈空闲时取出任务执行。Promise 回调属于微任务，会优先于下一个宏任务执行。

AI 生成的页面最该检查什么？

响应式（多尺寸实测）、语义化与可访问性（按钮、表单标签、alt、对比度）、XSS（是否用 innerHTML 插入数据）、性能（图片尺寸、无用依赖）、状态完整性（加载、空、错误态）。
