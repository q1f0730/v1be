React 服务端组件 (RSC)

React Server Components

🎓 专业模式
🎯一句话🧸打个比方🎬动起来看📊对比表👣怎么做💥翻车现场🤖给 AI 的话✅小测一下📚词汇
🎯 01 · 一句话

部分组件在服务器上做好，再送给浏览器

🧸 02 · 打个比方

像餐厅后厨把菜做好端上来。你桌上只放要动手的调料。不用自己带锅。

  • 🖥️ 默认在服务器跑，能直接查数据库
  • 📉 发给浏览器的代码更少、更快
  • 🖱️ 要点击交互，得标 use client
🎬 03 · 动起来看
🖥️服务端组件
🖱️客户端组件

👀 默认在服务器，要交互才去浏览器

👣 05 · 怎么做
  1. 1

    📚 知道 Next.js App Router 默认用它

  2. 2

💥 06 · 翻车现场

小陈在服务端组件里写了按钮点击。页面一直报错，查了一下午才发现。

🤖 07 · 给 AI 的话
我在用 Next.js App Router。请检查哪些组件需要交互、该标 use client，其余保持服务端组件。
✅ 08 · 小测一下

服务端组件不能做什么？

💡 它只在服务器跑，浏览器里的点击要交给客户端组件。
