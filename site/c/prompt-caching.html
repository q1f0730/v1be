🎯 一句话

重复的提示词开头存起来，省钱又快

🧸 打个比方

食堂阿姨提前打好底饭。来人只加菜就行。不用每份都从头盛。

  • 📌 固定内容放最前面才能命中
  • 💰 命中缓存的部分便宜很多
  • ⏱️ 缓存几分钟没用就会过期

🎬 动起来看

📦
缓存的开头⏱️ 几分钟有效⌛ 时间到 → 失效

👀 到时间没用，缓存就失效

📊 提示词怎么排

做法能命中缓存吗评价
固定说明放最前能✅ 对
时间戳放最前不能❌ 错
每次改开头不能❌ 错

👣 你该怎么做

  1. 1

    📄 找出每次都一样的长说明

  2. 2

    ⬆️ 把它放在提示词最前面

  3. 3

    🤖 让 AI 帮你打开缓存设置

💥 翻车现场

在系统提示词第一行写了当前时间，每次都不一样，缓存一次都没命中。

🤖 复制给 AI 的话

请检查我的 API 调用：把固定的系统提示词和文档放在最前面并开启提示词缓存，变化的内容放到最后。

💡 缓存按开头匹配，开头一变就失效。
