API版本控制策略

API Versioning

📐 01 · 定义

API 版本控制（API Versioning）是在接口发生不兼容变更时，让新旧契约并存、客户端按自己的节奏迁移的策略。它属于 API 生命周期治理层，常见载体有 URL 路径、请求头、查询参数或日期版本，配合弃用（Deprecation）与下线（Sunset）流程，避免一次改动打断所有调用方。

⚙️ 02 · 原理
  1. 1

    先区分兼容变更（新增可选字段、新接口）与破坏性变更（删字段、改类型、改语义）。

  2. 2

    兼容变更直接发布；只有破坏性变更才引入新版本，如 /v2 路径或新的版本头取值。

  3. 3

    网关或路由层根据路径或头部把请求分发到对应版本的处理逻辑或适配层。

  4. 4

    旧版本标记弃用，通过文档、响应头（Deprecation、Sunset）和邮件通知调用方。

  5. 5

    持续监控旧版本调用量，降到可接受水平且过了公告期后再正式下线。

🔤 03 · 术语
破坏性变更 (Breaking Change)
让现有客户端代码出错或语义改变的修改。
Sunset 响应头
RFC 8594 定义，声明资源预计停止服务的时间。
Deprecation 响应头
RFC 9745 定义，标记资源已被弃用。
日期版本 (Date-based Versioning)
以发布日期作版本号，按账号固定默认版本。
容错读取 (Tolerant Reader)
客户端忽略未知字段，提升向前兼容。
💻 04 · 代码
Express 路径版本与弃用头typescript
import express from "express";

const app = express();
const v1 = express.Router();
const v2 = express.Router();

// v1：返回 name 单字段（已弃用）
v1.get("/users/:id", (req, res) => {
  res.set("Deprecation", "@1767225600"); // RFC 9745：弃用起始时间戳
  res.set("Sunset", "Thu, 01 Jul 2027 00:00:00 GMT");
  res.set("Link", '</v2/users>; rel="successor-version"');
  res.json({ id: req.params.id, name: "Ada Lovelace" });
});

// v2：破坏性变更，拆为两个字段
v2.get("/users/:id", (req, res) => {
  res.json({ id: req.params.id, firstName: "Ada", lastName: "Lovelace" });
});

app.use("/v1", v1);
app.use("/v2", v2);
app.listen(3000);

新旧版本并存，旧版本通过响应头告知弃用与下线时间及替代版本；日期为示例。

⚖️ 06 · 方案取舍

大版本整体切换 (/v1→/v2)

优点边界清晰，易沟通

代价迁移成本集中，旧代码长期并存

适用公开 API、变更幅度大

日期版本 + 转换层

优点小步演进，客户端按需升级

代价服务端需维护版本转换链

适用大型平台型 API

不版本化，只做兼容演进

优点无多版本维护负担

代价设计受限，错误难以修正

适用内部 API 且调用方可同步升级

🕳️ 07 · 常见坑

  • ✗删除或重命名字段却不升版本

    ✓破坏性变更必须新版本；兼容期内新旧字段并存

  • ✗每次小改都开新版本，版本爆炸

    ✓兼容变更直接发布，只为破坏性变更升版本

  • ✗旧版本无限期保留，没人敢下线

    ✓制定弃用政策与时间表，按调用量监控推进下线

  • ✗把枚举新增值当作兼容变更

    ✓客户端可能穷举匹配，新增枚举值需提前公告或视为破坏性

☑️ 08 · 检查清单
🎤 09 · 面试追问
哪些变更算破坏性？

删除或重命名字段、改变字段类型或含义、新增必填参数、收紧校验、改变错误码或默认行为、改变分页或排序语义。新增可选字段、新增接口一般兼容，但前提是客户端容忍未知字段。

日期版本是怎么运作的？

每个账号固定一个默认 API 版本，请求可用头部覆盖。服务端内部只实现最新逻辑，再通过一系列版本转换把响应降级到客户端请求的版本，从而支持细粒度演进。

如何安全下线旧版本？

提前公告弃用与日期，响应头提示，按调用方统计流量并逐一通知；临近下线可做短时「熔断演练」暴露未迁移者，最终返回 410 Gone 并提供迁移文档。
