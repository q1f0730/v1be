🎯 01 · 一句话

把大量请求打包交给模型慢慢处理

🧸 02 · 打个比方

像洗衣店的“次日取”。不急着要，价格就便宜。今天送去，明天来拿。

  • 💰 价格通常比实时调用便宜
  • 🕐 结果要等，一般一天之内
  • 📄 适合打标签、翻译、批量总结
🎬 03 · 动起来看
📄📄📄📄📄
一千条任务
🤖模型批处理

👀 任务排队，空闲时统一处理

📊 04 · 对比表

实时 vs 批量

对比项实时调用批量接口
速度几秒出结果最长约一天
价格原价通常更便宜
适合聊天、客服离线大任务
👣 05 · 怎么做
  1. 1

    📋 把任务整理成一行一条

  2. 2

    📤 上传文件并提交批处理

  3. 3

    📥 完成后下载结果对一下

💥 06 · 翻车现场

小冯用实时接口给十万条评论打标签。一晚花了几百块，其实用批量能省一大截。

我有一份 5000 条商品评论的表格。请帮我写脚本，用批量接口给每条打上“好评/差评/中性”标签，并在完成后合并结果。
