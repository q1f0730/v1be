SSH 远程登录与密钥

SSH

📐 01 · 定义

SSH（Secure Shell）是用于在不安全网络上安全登录和执行命令的加密协议，默认使用 TCP 22 端口。它在传输层完成密钥交换与服务器身份验证，再以密码或公钥方式认证用户，并支持端口转发、文件传输（scp/sftp）。开发中最常见的用途是登录云服务器和以 SSH 方式访问 Git 托管平台。

⚙️ 02 · 原理
  1. 1

    客户端连接服务器，双方协商协议版本与算法，并通过密钥交换（如 Curve25519）生成会话密钥，后续流量全部加密。

  2. 2

    服务器出示主机公钥，客户端与 known_hosts 中的记录比对；首次连接会提示指纹，用于防范中间人攻击。

  3. 3

    用户认证阶段，公钥认证要求客户端用私钥对会话数据签名，服务器用 authorized_keys 中的公钥验证。

  4. 4

    认证成功后在加密通道内开启会话：交互式 shell、远程命令、端口转发或 SFTP 子系统。

  5. 5

    ssh-agent 在内存中持有解锁后的私钥，供多次连接复用；agent 转发可在跳板机上使用本地密钥，但有安全风险。

🔤 03 · 术语
authorized_keys
服务器上允许登录的公钥列表，位于用户 ~/.ssh 下。
known_hosts
客户端记录已信任服务器主机公钥的文件。
Ed25519
基于椭圆曲线的签名算法，密钥短、速度快，当前推荐类型。
ssh-agent
保存解密后私钥的后台进程，避免反复输入口令。
端口转发 (Port Forwarding)
用 -L/-R 把本地或远端端口经 SSH 隧道转发。
跳板机 (Bastion / ProxyJump)
通过 -J 经中间主机访问内网服务器。
💻 04 · 代码
生成密钥、配置别名并加固bash
# 1. 生成 Ed25519 密钥（建议设置口令）
ssh-keygen -t ed25519 -C "you@example.com"

# 2. 公钥上传到服务器（或粘贴到 GitHub 设置）
ssh-copy-id -i ~/.ssh/id_ed25519.pub deploy@203.0.113.10
ssh -T git@github.com          # 测试 GitHub 连接

# 3. ~/.ssh/config 设置别名
cat >> ~/.ssh/config <<CFG
Host prod
  HostName 203.0.113.10
  User deploy
  IdentityFile ~/.ssh/id_ed25519
CFG
ssh prod

# 4. 服务器 /etc/ssh/sshd_config 加固后重载
#   PasswordAuthentication no
#   PermitRootLogin no
sudo systemctl reload ssh   # 部分发行版服务名为 sshd

覆盖密钥生成、公钥分发、客户端别名与禁用密码登录；改配置前保持一个已登录会话以防锁死。

认证方式对比

方式安全性适用场景
密码认证易被暴力破解临时或内网测试，不推荐公网
公钥认证强，私钥不出本机服务器登录、Git 推送
SSH 证书 (CA 签发)强，可设置有效期集中吊销大规模团队与服务器集群

个人公钥直接加入服务器

优点简单直接

优点集中签发、自动过期

🕳️ 07 · 常见坑

  • ✗私钥不设口令且同步到网盘

    ✓设置口令、配合 ssh-agent，私钥只存本机

  • ✗看到主机指纹变化直接删 known_hosts 继续

    ✓先核实服务器是否重装或换 IP，确认后再更新记录

  • ✗修改 sshd_config 后直接断开会话

    ✓保留当前会话，新开窗口测试登录成功后再退出

  • ✗对不可信跳板机开启 agent 转发

    ✓改用 ProxyJump，避免远端借用你的 agent

🎤 09 · 面试追问
SSH 如何防止中间人攻击？

依靠服务器主机密钥。首次连接时用户应通过可信渠道核对指纹，客户端将其记入 known_hosts；之后每次连接都校验主机密钥，若不一致会发出强烈警告并拒绝连接。也可用 SSHFP DNS 记录或主机证书自动验证。

公钥认证时私钥会被发送到服务器吗？

不会。服务器只持有公钥，客户端用私钥对包含会话标识的数据签名，服务器用公钥验证签名。私钥始终留在本机，因此即使服务器被攻破，攻击者也拿不到你的私钥。

-L 和 -R 端口转发有什么区别？

-L 是本地转发：把本机端口经 SSH 转发到远端可达的地址，常用于访问只在内网监听的数据库。-R 是远程转发：把远端服务器的端口转回本机，可让外部访问本地服务，类似简易内网穿透。
