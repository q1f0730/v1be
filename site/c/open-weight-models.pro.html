开放权重模型 (Llama / Qwen / DeepSeek)

Open-Weight Models

📐 01 · 定义

开放权重模型（Open-Weight Model）指公开发布训练后参数文件、允许下载并自行推理部署的模型，如 Llama、Qwen、DeepSeek、Mistral 等系列。它属于模型供给层：与只能经 API 访问的闭源模型相对。注意「开放权重」不等于「开源」：训练数据与训练代码常不公开，使用条款由各自许可证决定。

⚙️ 02 · 原理
  1. 1

    厂商完成预训练与对齐后，把权重（通常为 safetensors 等格式）与分词器、配置文件发布到 Hugging Face 等平台。

  2. 2

    用户按许可证下载权重，选择推理方式：transformers 直接加载、vLLM 等推理引擎服务化，或 Ollama/llama.cpp 跑量化版本。

  3. 3

    显存需求约等于参数量 × 每参数字节数（FP16 为 2 字节）再加 KV Cache 与运行开销，决定能否在本机运行。

  4. 4

    可在本地做量化、LoRA 微调、蒸馏等二次加工，并通过 OpenAI 兼容接口暴露给上层应用或编程 Agent。

  5. 5

    数据全程留在自有环境，适合合规敏感场景；代价是运维、硬件与效果调优都由自己承担。

🔤 03 · 术语
权重 (Weights)
训练得到的模型参数张量，推理时加载到显存或内存参与计算。
开放权重 vs 开源 (Open Weights vs Open Source)
前者只公开参数；按 OSI 定义，开源 AI 还需提供足够的数据信息与代码。
社区许可证 (Community License)
如 Llama 系列的自定义许可，可能限制用户规模、用途或要求署名。
Instruct / Base 版本
Base 只做过预训练续写；Instruct 经指令微调，适合对话与工具调用。
safetensors
Hugging Face 推出的张量存储格式，加载时不执行任意代码，比 pickle 安全。
💻 04 · 代码
用 transformers 本地推理python
# pip install transformers torch accelerate
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "Qwen/Qwen2.5-0.5B-Instruct"  # 小模型，CPU 也能跑
tok = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id, torch_dtype="auto", device_map="auto"
)

messages = [{"role": "user", "content": "用一句话解释什么是 API"}]
# 用模型自带的对话模板拼接提示，避免格式错位
text = tok.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
inputs = tok([text], return_tensors="pt").to(model.device)

out = model.generate(**inputs, max_new_tokens=128)
# 只解码新生成的部分
print(tok.decode(out[0][inputs.input_ids.shape[1]:], skip_special_tokens=True))

权重首次运行时从 Hugging Face 下载并缓存；对话模型必须套用其 chat template。

🕳️ 07 · 常见坑

  • ✗把「开放权重」当成可随意商用

    ✓逐条读许可证：用户规模、用途限制、署名与再分发要求

  • ✗只按参数量估显存，忽略 KV Cache 与长上下文

    ✓按精度算权重占用后，再为上下文和并发预留余量

  • ✗下载 Base 版本却拿来做对话

    ✓对话与工具调用选 Instruct/Chat 版本，并使用官方模板

  • ✗从来路不明的仓库下载 pickle 权重

    ✓优先官方组织与 safetensors 格式，核对哈希

🎤 09 · 面试追问
开放权重模型和开源模型有什么区别？

开放权重只公开参数，用户可推理和微调；开源（按 OSI 的开源 AI 定义）还要求公开足够的训练数据信息和训练/推理代码，并给予使用、研究、修改、分享自由。很多模型附带限制性许可证，因此只能称开放权重。

什么情况下你会建议自部署而不是调 API？

数据不能出域的合规场景；调用量大且稳定、按量计费明显更贵；需要深度定制（微调、约束解码）；需要离线或低延迟内网部署。反之，量小、追求最强效果、团队无 GPU 运维能力时用 API 更划算。

7B 模型 FP16 推理大致要多少显存？

权重约 7×10⁹×2 字节≈14 GB，再加 KV Cache（随上下文长度和并发增长）与框架开销，单卡通常需 16 GB 以上较稳。4-bit 量化后权重约 4 GB 左右，可在消费级显卡运行，但有一定精度损失。
