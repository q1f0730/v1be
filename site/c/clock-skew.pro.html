时钟偏斜

Clock Skew

🧸 回到小白版
📐定义⚙️原理🔤术语💻代码📊参数对比⚖️方案取舍🕳️常见坑☑️检查清单🎤面试追问🔗延伸阅读
📐 01 · 定义

时钟偏斜（Clock Skew）指分布式系统中不同机器的本地时钟在同一时刻读数不同，且由于晶振频率差异（漂移）会随时间扩大。即使使用 NTP 同步，也只能把误差控制在一定范围内。依赖墙上时钟做排序、超时、锁过期或冲突合并时，偏斜可能导致数据丢失或逻辑错误。

⚙️ 02 · 原理
  1. 1

    来源：每台机器的晶振频率略有差异，本地时钟以不同速度走，误差持续累积。

  2. 2

    同步：NTP/chrony 定期与上游时间源校对，逐步调整速率或直接跳变修正时间。

  3. 3

    误差：同步受网络延迟不对称影响，偏差只能缩小到一个范围而无法完全消除。

  4. 4

    影响：用时间戳比较不同机器上的事件先后可能出错，例如最后写入胜出丢更新。

  5. 5

    对策：计时用单调时钟，排序用逻辑时钟或混合逻辑时钟，必要时等待误差上界。

🔤 03 · 术语
时钟漂移 (Clock Drift)
时钟走速与真实时间的偏差率，导致误差随时间累积。
单调时钟 (Monotonic Clock)
只增不减、不受校时跳变影响，适合测量时间间隔。
Lamport 时钟
逻辑计数器，保证因果相关事件的时间戳单调递增。
混合逻辑时钟 (HLC)
结合物理时间与逻辑计数，接近真实时间又保持因果顺序。
TrueTime
Spanner 的时间 API，返回带误差上界的时间区间。
💻 04 · 代码
单调时钟与 Lamport 时钟python
import time

# 1) 计算耗时/超时：用单调时钟，不受 NTP 校时跳变影响
start = time.monotonic()
time.sleep(0.2)
elapsed = time.monotonic() - start      # 用 time.time() 相减可能为负或偏大

# 2) 跨节点事件排序：Lamport 逻辑时钟
class LamportClock:
    def __init__(self):
        self.t = 0
    def tick(self):                     # 本地事件或发送消息前
        self.t += 1
        return self.t
    def recv(self, remote_t):           # 收到消息时取较大值再加一
        self.t = max(self.t, remote_t) + 1
        return self.t

a, b = LamportClock(), LamportClock()
msg_t = a.tick()                        # A 发送消息，时间戳 1
print(b.recv(msg_t), round(elapsed, 2)) # B 收到后时间戳 2，保证晚于发送

墙上时钟用于展示，单调时钟用于计时，逻辑时钟用于跨节点的因果排序。

📊 05 · 参数对比

时间方案对比

方案提供什么局限
NTP 同步墙上时钟近似真实时间有误差，可能回跳
单调时钟单机内可靠的时间间隔不能跨机器比较
Lamport/向量时钟因果顺序与真实时间无关
HLC / TrueTime接近真实时间且有序需要实现或专用硬件支持
⚖️ 06 · 方案取舍

依赖 NTP 时间戳

优点简单直观，可读性好

代价偏斜导致排序错误

适用日志展示、粗粒度统计

逻辑时钟/版本号

优点不依赖物理时间，排序可靠

代价不反映真实时间

适用冲突检测、事件因果

HLC

优点兼顾因果与近似物理时间

代价实现更复杂

适用分布式数据库、跨节点事务

🕳️ 07 · 常见坑

  • ✗用 time.time() 计算超时或耗时，校时后出现负值

    ✓计时一律使用单调时钟

  • ✗用各节点本地时间戳做最后写入胜出

    ✓使用版本号、逻辑时钟或由单一节点分配顺序

  • ✗分布式锁过期依赖不同机器时钟一致

    ✓锁使用存储端计时并配合防护令牌

  • ✗未监控 NTP 同步状态，偏差悄悄扩大

    ✓监控时钟偏移并在超阈值时告警或摘除节点

☑️ 08 · 检查清单
🎤 09 · 面试追问
为什么不能用时间戳判断跨节点事件先后？

不同机器时钟存在偏斜，NTP 也只保证误差在一定范围内；两事件间隔小于该误差时，时间戳大小与真实先后可能相反。需要因果顺序时应使用逻辑时钟或由单点分配序号。

Spanner 怎么解决时钟问题？

TrueTime 借助 GPS 和原子钟把时钟误差控制在较小的已知范围内，并返回时间区间。提交时等待误差区间过去（commit wait）再对外可见，从而保证时间戳顺序与真实提交顺序一致。

chrony 的跳变和渐调有什么区别？

跳变（step）直接把时钟设为正确值，修正快但会造成时间回退或跳跃；渐调（slew）微调时钟速率逐步追上，时间连续但修正慢。生产中通常只在启动时允许跳变，运行时渐调。
