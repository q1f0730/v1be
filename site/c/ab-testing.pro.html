A/B 测试

A/B Testing

📐 01 · 定义

A/B 测试是一种在线随机对照实验：把用户随机分配到对照组（A）和实验组（B），在同一时间段内只改变一个因素，比较预先定义的指标，用统计检验判断差异是否超出随机波动。它把产品决策从主观判断转为因果推断，常与功能开关、埋点分析平台配合使用。

⚙️ 02 · 原理
  1. 1

    实验前定义假设、主指标（如转化率）、护栏指标（如退款率、延迟）和最小可检测效应（MDE）。

  2. 2

    根据基线、MDE、显著性水平（常用 α=0.05）和统计功效（常用 80%）计算每组所需样本量与实验时长。

  3. 3

    用稳定的用户 ID 哈希分桶，保证同一用户始终看到同一版本，分流比例与预期一致。

  4. 4

    实验运行满预定样本量或完整周期（通常覆盖至少一周以消除周内效应），期间不因中途结果提前停止。

  5. 5

    用双比例 z 检验、t 检验等方法计算 p 值与置信区间，同时检查样本比例失衡（SRM）与护栏指标后再决策。

🔤 03 · 术语
最小可检测效应 (MDE)
实验设计时希望可靠检测到的最小差异。
统计功效 (Power)
真实存在差异时检测到它的概率，常取 80%。
样本比例失衡 (SRM)
实际分组比例显著偏离设计比例，提示分流或埋点有问题。
偷看问题 (Peeking)
反复查看并在显著时停止，会显著抬高假阳性率。
护栏指标 (Guardrail Metric)
不希望被实验损害的关键指标，如收入、错误率。
新奇效应 (Novelty Effect)
用户因新鲜感短期行为变化，长期可能消退。
💻 04 · 代码
样本量估算与显著性检验python
import hashlib
from statsmodels.stats.power import NormalIndPower
from statsmodels.stats.proportion import proportion_effectsize, proportions_ztest

# 1. 稳定分桶：同一用户永远进同一组
def bucket(user_id: str, exp: str = "signup_btn") -> str:
    h = int(hashlib.sha256(f"{exp}:{user_id}".encode()).hexdigest(), 16)
    return "B" if h % 100 < 50 else "A"

# 2. 样本量：基线 10%，希望检测到提升到 11%
es = proportion_effectsize(0.11, 0.10)
n = NormalIndPower().solve_power(effect_size=es, alpha=0.05, power=0.8)
print(f"每组约需 {n:.0f} 人")

# 3. 实验结束后检验（示例数据）
conversions = [1180, 1050]      # B, A 转化人数
visitors = [10000, 10000]
z, p = proportions_ztest(conversions, visitors)
print(f"z={z:.2f}, p={p:.4f}")  # p < 0.05 才认为差异显著

展示哈希分桶、事前样本量计算和事后双比例 z 检验；10%→11% 这类小提升每组需上万用户。

📊 05 · 参数对比

常见实验问题诊断

现象可能原因处理
A/B 人数比例明显不是 50:50分流 bug、埋点丢失、机器人流量做 SRM 卡方检验，排查后再看结果
第一天显著，之后消失新奇效应或偷看导致假阳性跑满预定时长，按周期分析
主指标涨、收入跌局部优化损害整体设置护栏指标并一票否决
多个指标中有一个显著多重比较预先指定主指标，或做多重检验校正
⚖️ 06 · 方案取舍

固定样本频率学派检验

优点方法成熟，解释标准

代价必须跑满样本，不能中途看

适用多数产品实验

序贯检验 / 始终有效推断

优点允许持续监控并提前停止

代价方法更复杂，功效略低

适用需要快速止损的实验

多臂老虎机 (Bandit)

优点自动把流量导向更优版本

代价因果估计不如 A/B 清晰

适用短期活动、推荐位优化

🕳️ 07 · 常见坑

  • ✗看到 p<0.05 就立即停止实验

    ✓预先确定样本量和时长，或使用序贯检验方法

  • ✗按会话随机而非按用户，同一人看到两版

    ✓以稳定用户 ID 分桶，登录前后做身份关联

  • ✗一次实验同时改文案、颜色和布局

    ✓一次只改一个因素，或用多因素实验设计

  • ✗忽略 SRM 直接解读结果

    ✓先检验分组比例，失衡说明数据不可信

☑️ 08 · 检查清单
🎤 09 · 面试追问
什么是偷看问题，为什么危险？

在固定样本检验中反复查看结果，只要某一刻 p<0.05 就停止，相当于做了多次检验，假阳性率会远高于名义的 5%。解决方法是预先固定样本量，或采用序贯检验、始终有效置信区间等支持持续监控的方法。

如何确定实验需要多少样本？

需要基线转化率、最小可检测效应、显著性水平和统计功效。效应越小、基线越低，所需样本越多，且大致与效应的平方成反比。若所需样本超出流量能力，应选更敏感的指标、增大改动幅度或接受更长周期。

统计显著就代表应该上线吗？

不一定。还要看效应大小是否有业务意义、置信区间下限是否可接受、护栏指标是否受损、是否存在新奇效应，以及实现与维护成本。显著只说明差异不太可能是随机产生的。
