数据合规 (GDPR / 个人信息保护法)

Data Privacy Compliance

📐 01 · 定义

数据合规指在收集、存储、使用、共享和删除个人信息时满足法律要求，代表法规有欧盟 GDPR（2018 年 5 月起适用）、中国《个人信息保护法》（2021 年 11 月 1 日起施行）与美国加州 CCPA/CPRA。它属于法务与产品治理层，核心原则包括合法依据、告知同意、目的限制、最小必要、安全保障与个人权利响应。以下为工程视角概述，不构成法律意见。

⚙️ 02 · 原理
  1. 1

    数据盘点：记录收集哪些个人信息、目的、法律依据、存储位置、保留期限与共享对象。

  2. 2

    确定处理的合法性基础：GDPR 规定同意、合同履行、法定义务等六类；PIPL 以同意为主并列明其他情形。

  3. 3

    通过隐私政策告知，敏感个人信息需单独同意；默认设置遵循最小必要（Privacy by Default）。

  4. 4

    实施技术与组织措施：加密、访问控制、脱敏、审计；高风险处理前做影响评估（DPIA / 个人信息保护影响评估）。

  5. 5

    建立权利响应与事件流程：查阅、更正、删除、可携带、撤回同意；数据泄露按法规时限通知监管与用户。

🔤 03 · 术语
数据控制者 / 个人信息处理者
决定处理目的与方式的主体，承担主要合规责任。
数据处理者 / 受托方
代表控制者处理数据的一方，如云服务、模型 API 供应商。
DPIA
数据保护影响评估，针对高风险处理事先评估与缓解。
DSAR
数据主体访问请求，用户要求查阅或获取其个人数据。
跨境传输 (Cross-border Transfer)
向境外提供个人信息，需满足相应法定机制。
敏感个人信息
生物识别、医疗健康、金融账户、行踪轨迹等，泄露易造成严重危害。
💻 04 · 代码
数据保留与删除请求处理sql
-- 1. 按保留策略清理：超过 180 天的原始访问日志直接删除
DELETE FROM access_logs WHERE created_at < now() - interval '180 days';

-- 2. 用户注销/删除请求：在一个事务中处理该用户的个人数据
BEGIN;
-- 订单因财税法规需保留：去标识化而不是删除
UPDATE orders
   SET receiver_name = NULL, receiver_phone = NULL, address = NULL
 WHERE user_id = :uid;
DELETE FROM user_profiles   WHERE user_id = :uid;
DELETE FROM chat_messages   WHERE user_id = :uid;
UPDATE users SET email = NULL, phone = NULL, deleted_at = now()
 WHERE id = :uid;
-- 记录处理结果以备审计（不含被删除的内容本身）
INSERT INTO privacy_requests (user_id, kind, done_at) VALUES (:uid, 'erasure', now());
COMMIT;
-- 备份、搜索索引、分析仓库、第三方处理者中的副本需另行处理

删除请求要覆盖所有副本；有法定保存义务的数据做去标识化而非直接删除。

⚖️ 06 · 方案取舍

隐私设计 (Privacy by Design)

优点从源头减少数据，后期改造成本低

代价前期需更多设计投入

适用新产品与新功能

合规后补

优点早期速度快

代价改造数据模型与流程代价大，风险高

适用不推荐，仅作临时状态

采购合规服务（同意管理、DSAR 工具）

优点快速满足流程要求

代价费用与集成成本

适用用户量大、多法域运营

🕳️ 07 · 常见坑

  • ✗把用户数据发给第三方模型 API 却未告知

    ✓在隐私政策中披露，签数据处理协议，确认不用于训练

  • ✗删除只删主表，忘了备份、日志、分析仓库

    ✓建立数据地图，删除流程覆盖全部副本或按保留期自然过期

  • ✗预先勾选同意或捆绑同意

    ✓同意需主动、具体、可撤回，敏感信息单独同意

  • ✗收集「以后可能有用」的数据

    ✓按明确目的最小化收集，并设定保留期限

🎤 09 · 面试追问
GDPR 的「合法利益」能替代同意吗？

可以作为合法性基础之一，但需做平衡测试，证明处理必要且不凌驾于个人权利之上，并允许反对。营销、儿童数据等场景需谨慎，具体应由法务判断。

个保法下向境外 AI 服务发送用户数据要注意什么？

这属于个人信息出境：需告知并取得单独同意，满足安全评估、认证或标准合同等法定条件之一（视数据量与类型），做影响评估并保留记录。具体门槛以监管最新规定为准。

工程上如何支持「被遗忘权」？

维护数据地图知道数据在哪；用户 ID 作为可追踪的关联键；删除任务覆盖数据库、对象存储、搜索、分析与第三方；备份按保留期过期；记录处理结果。
