无服务器 GPU 推理

Serverless GPU

📐 01 · 定义

无服务器 GPU（Serverless GPU）指由平台按请求自动启动、扩缩和回收 GPU 容器，用户只为实际运行时间（通常按秒）付费，无需管理服务器。它属于模型部署与基础设施层，适合部署自定义或开源模型、负载波动大的推理与批处理任务。代表平台有 Modal、Replicate、RunPod Serverless 等，核心挑战是冷启动。

⚙️ 02 · 原理
  1. 1

    开发者定义容器镜像（依赖、模型权重来源）、GPU 类型和处理函数，提交到平台。

  2. 2

    请求到达时，若无热容器，平台调度 GPU、启动容器并加载模型权重，即冷启动。

  3. 3

    容器处理请求，平台根据排队长度与并发上限自动扩容出更多 GPU 副本。

  4. 4

    空闲超过设定时间后容器被回收并停止计费；可配置最小常驻副本消除冷启动，但需持续付费。

  5. 5

    冷启动优化手段包括：权重放入镜像或高速卷、容器启动时预加载模型、内存/GPU 快照等平台特性。

🔤 03 · 术语
冷启动 (Cold Start)
从零启动容器并加载模型到可服务的延迟。
缩容到零 (Scale to Zero)
无请求时不保留实例，不产生计算费用。
最小副本数 (Min Containers)
常驻热实例数量，以费用换取无冷启动。
空闲回收窗口 (Scaledown Window)
最后一次请求后容器保持存活的时间。
模型权重卷 (Volume)
持久化存储权重，避免每次启动重新下载。
💻 04 · 代码
Modal 部署 GPU 推理函数python
import modal

image = modal.Image.debian_slim().pip_install("transformers", "torch", "accelerate")
app = modal.App("qwen-api", image=image)

@app.cls(gpu="A10G", scaledown_window=300)   # 空闲 5 分钟后回收
class Model:
    @modal.enter()                    # 容器启动时加载一次，之后的请求复用
    def load(self):
        from transformers import pipeline
        self.pipe = pipeline("text-generation", model="Qwen/Qwen2.5-0.5B-Instruct",
                             device_map="cuda")

    @modal.method()
    def generate(self, prompt: str) -> str:
        out = self.pipe(prompt, max_new_tokens=128)
        return out[0]["generated_text"]

@app.local_entrypoint()
def main():
    print(Model().generate.remote("用一句话介绍 KV 缓存"))
# 运行：modal run app.py   部署：modal deploy app.py

@modal.enter 把模型加载放在容器启动时；scaledown_window 控制空闲回收时间。

📊 05 · 参数对比

GPU 推理部署方式对比

方式计费冷启动适用
托管模型 API按 Token无（平台承担）通用大模型能力
Serverless GPU按秒运行时间有，秒级到分钟级自定义模型、波动负载
专用 GPU 实例按小时/包月无（常驻）稳定高负载
自建 GPU 集群硬件 + 运维无超大规模、强合规

优点空闲零成本

优点无冷启动、延迟稳定

🕳️ 07 · 常见坑

  • ✗每次启动都从 Hugging Face 下载权重

    ✓把权重放进镜像或持久化卷，并在容器启动时预加载

  • ✗在请求处理函数里加载模型

    ✓模型加载放在容器初始化钩子中，只执行一次

  • ✗设置常驻副本后忘记，空闲照常计费

    ✓按时段调整最小副本数，设置预算告警

  • ✗选了远超需要的 GPU 型号

    ✓按模型显存与吞吐需求选择型号，压测后再定

🎤 09 · 面试追问
Serverless GPU 和托管模型 API 如何选择？

需要通用强模型、无定制需求，用托管 API 最省事；需要运行自定义/微调/开源模型（含图像、语音），或数据控制要求高、负载波动大，用 Serverless GPU。持续高负载时专用实例可能更便宜。

冷启动由哪些部分组成？

调度 GPU 机器、拉取镜像、启动容器与运行时、下载或读取权重、把权重加载到 GPU 并完成初始化。大模型通常以权重传输和加载为主，可通过缓存、预加载与快照缩短。

如何估算 Serverless GPU 成本？

单次请求 GPU 秒数 × 每秒单价 × 请求量，加上冷启动与空闲窗口内的计费时间、常驻副本费用。再与托管 API 按 Token 成本和专用实例月费对比。
