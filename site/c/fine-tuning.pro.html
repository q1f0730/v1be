微调 (Fine-tuning)

Fine-Tuning

📐 01 · 定义

微调（Fine-tuning）是在预训练模型基础上，用特定任务或领域的数据继续训练，调整模型权重以改变其行为、格式或领域能力的方法。按更新范围分为全参数微调与参数高效微调（PEFT，如 LoRA），按目标分为监督微调（SFT）与偏好优化（如 DPO）。它位于模型定制层，与提示工程、RAG 互补。

⚙️ 02 · 原理
  1. 1

    准备数据：整理成指令-回答或多轮对话格式，清洗、去重并划分训练集与验证集。

  2. 2

    选择基座模型与方法：全参数微调更新全部权重；LoRA 冻结原权重，只训练低秩适配矩阵。

  3. 3

    设置超参数（学习率、轮数、批大小、LoRA 秩 r 等），在训练集上最小化损失。

  4. 4

    在验证集与独立评测集上比较微调前后效果，并检查通用能力是否退化。

  5. 5

    部署时合并适配器权重或在推理时动态加载适配器，一个基座可挂载多个 LoRA。

🔤 03 · 术语
监督微调 (SFT)
用标注好的输入-输出对训练模型模仿目标回答。
LoRA
在权重旁加低秩矩阵并只训练它们，参数量和显存大幅下降。
QLoRA
在 4 位量化基座上训练 LoRA，进一步降低显存。
DPO
直接偏好优化，用成对的好/坏回答训练，无需单独奖励模型。
灾难性遗忘 (Catastrophic Forgetting)
微调后模型丢失原有通用能力。
💻 04 · 代码
用 PEFT 给模型加 LoRApython
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import LoraConfig, get_peft_model

base = "Qwen/Qwen2.5-0.5B-Instruct"    # 小模型便于演示
tokenizer = AutoTokenizer.from_pretrained(base)
model = AutoModelForCausalLM.from_pretrained(base)

config = LoraConfig(
    r=16,                      # 低秩维度，越大容量越高
    lora_alpha=32,             # 缩放系数
    lora_dropout=0.05,
    target_modules=["q_proj", "v_proj"],   # 注入到注意力投影层
    task_type="CAUSAL_LM",
)
model = get_peft_model(model, config)
model.print_trainable_parameters()
# 输出可训练参数占比，通常远小于 1%

# 之后用 transformers Trainer 或 TRL 的 SFTTrainer 训练，
# 训练完 model.save_pretrained("lora-adapter") 只保存适配器权重
# 部署时可 model.merge_and_unload() 合并回基座

LoRA 只训练少量新增参数；target_modules 名称取决于具体模型结构。

📊 05 · 参数对比

定制模型行为的路径

方法改变什么成本适合
提示工程输入指令与示例最低大多数需求的起点
RAG推理时提供外部知识中知识频繁更新、需引用
LoRA 微调少量新增权重中固定格式、风格、领域任务
全参数微调全部权重高大规模数据与算力
⚖️ 06 · 方案取舍

先做提示工程 + RAG

优点迭代快，无需训练设施

代价提示词变长，成本与延迟上升

适用需求仍在变化、知识需更新

LoRA/QLoRA

优点显存需求低，可多适配器切换

代价容量有限，需要数据与评测

适用稳定任务需特定格式或风格

托管微调服务

优点免运维，按量付费

代价受平台支持的模型与参数限制

适用没有 GPU 团队

🕳️ 07 · 常见坑

  • ✗想用微调给模型灌输经常变化的知识

    ✓知识更新用 RAG，微调用于行为、格式和风格

  • ✗数据量少质量差，模型反而变笨

    ✓优先保证数据质量与一致性，先小规模实验

  • ✗只看训练损失，不做独立评测

    ✓用留出评测集对比基线，并检查通用能力退化

  • ✗训练数据含用户隐私或密钥

    ✓训练前脱敏与扫描，模型可能记住并复述训练数据

🎤 09 · 面试追问
微调和 RAG 怎么选？

需要模型掌握会变的事实、并能给出出处时用 RAG；需要稳定的输出格式、语气、特定任务技巧或缩短提示词时用微调。两者可结合：微调学会如何使用检索结果，RAG 提供最新知识。

LoRA 为什么能省显存？

冻结原始权重，只为部分层引入两个低秩矩阵 A、B 来近似权重更新，可训练参数和优化器状态大幅减少；QLoRA 再把冻结的基座量化到 4 位，使单卡微调更大模型成为可能。

如何发现微调导致的能力退化？

除目标任务评测外，保留一组通用能力和安全性评测（指令遵循、推理、拒答等），对比微调前后；可在训练数据中混入少量通用数据，或降低学习率、减少轮数缓解遗忘。
