直接偏好优化 (DPO)

DPO

🧸 回到小白版
📐定义⚙️原理🔤术语💻代码📊参数对比⚖️方案取舍🕳️常见坑☑️检查清单🎤面试追问🔗延伸阅读
📐 01 · 定义

直接偏好优化（DPO，Rafailov 等，2023）是一种偏好对齐方法：利用「同一提示下更好与更差回答」的成对数据，直接以分类式损失优化语言模型，无需像 RLHF 那样单独训练奖励模型并运行 PPO 强化学习。论文证明在相同的 KL 约束奖励最大化目标下，最优策略可用策略与参考模型的对数概率比表示，从而把强化学习化为监督学习。

⚙️ 02 · 原理
  1. 1

    准备偏好数据：每条包含提示 x、偏好回答 y_w（chosen）与较差回答 y_l（rejected）。

  2. 2

    冻结一份参考模型（通常是 SFT 后的模型），训练模型从同一初始化开始。

  3. 3

    计算隐式奖励 β·log(π_θ(y|x)/π_ref(y|x))，分别作用于偏好与较差回答。

  4. 4

    损失为 −log σ(隐式奖励差)：提高偏好回答相对参考模型的概率，同时降低较差回答的概率。

  5. 5

    β 控制偏离参考模型的程度；训练中常监控隐式奖励差距与偏好准确率，并用独立评测集检验真实效果。

🔤 03 · 术语
参考模型 (Reference Model)
训练中固定不变的初始策略，用来约束新模型不要偏离太远。
β (beta)
控制 KL 约束强度的超参数，越小越允许偏离参考模型，TRL 默认值以文档为准。
Bradley-Terry 模型
把两两偏好概率建模为两者奖励差的 sigmoid，是 DPO 推导的基础。
隐式奖励 (Implicit Reward)
由策略与参考模型对数概率比给出的奖励，无需显式奖励模型。
IPO / KTO / SimPO
DPO 的变体，分别改进过拟合、支持非成对数据、去除参考模型等。
💻 04 · 代码
TRL 训练 DPOpython
# pip install trl datasets ；模型与数据集名以官方文档为准
from datasets import load_dataset
from trl import DPOConfig, DPOTrainer

# 每条样本包含 prompt / chosen / rejected
train = load_dataset("trl-lib/ultrafeedback_binarized", split="train")

args = DPOConfig(
    output_dir="qwen-dpo",
    beta=0.1,                    # KL 约束强度
    learning_rate=5e-7,          # 全参数 DPO 常用很小的学习率
    per_device_train_batch_size=2,
    gradient_accumulation_steps=8,
    num_train_epochs=1,
    logging_steps=10,
)

trainer = DPOTrainer(
    model="Qwen/Qwen3-0.6B",     # 通常应从 SFT 后的模型开始
    args=args,
    train_dataset=train,
)
trainer.train()
# 观察日志中的 rewards/margins 与 rewards/accuracies

未传 ref_model 时 TRL 会自动用初始模型副本作为参考；超参数仅为示意，需按任务调优。

📊 05 · 参数对比

RLHF(PPO) 与 DPO 对比

维度RLHF + PPODPO
奖励模型需单独训练不需要（隐式奖励）
训练时采样在线生成回答离线使用固定数据
同时加载模型策略、参考、奖励、价值策略与参考
稳定性超参数敏感类监督学习，较稳定
探索新回答能受限于数据中的回答
⚖️ 06 · 方案取舍

DPO（离线偏好）

优点实现简单、资源省、训练稳定

代价无法探索数据外的更优回答

适用已有高质量偏好对，资源有限

在线/迭代 DPO

优点用当前模型生成新回答再标注，缓解分布偏移

代价需要持续标注或评审模型

适用需要多轮持续改进

PPO 等在线 RL

优点可持续探索，上限高

代价工程复杂、成本高

适用大规模对齐且有成熟基础设施

🕳️ 07 · 常见坑

  • ✗偏好数据中 chosen 普遍更长，模型学会啰嗦

    ✓检查长度偏差，平衡数据或使用长度归一化的变体

  • ✗直接在基座模型上做 DPO

    ✓先 SFT 让模型分布接近偏好数据，再做 DPO

  • ✗学习率过大导致输出退化

    ✓使用很小的学习率并监控生成样例与评测分

  • ✗只看训练偏好准确率

    ✓用独立评测集或人工评估检验真实质量

☑️ 08 · 检查清单
🎤 09 · 面试追问
DPO 为什么不需要奖励模型？

在带 KL 约束的奖励最大化目标下，最优策略与奖励存在闭式关系：奖励可表示为策略与参考模型的对数概率比乘 β 加上只与提示有关的项。代入 Bradley-Terry 偏好模型后该项抵消，损失只依赖策略与参考模型的概率，于是可直接优化策略。

β 的作用是什么，如何调？

β 对应 KL 约束强度。β 小，模型可大幅偏离参考，偏好拟合更强但易过拟合或退化；β 大则更保守。常从 0.1 附近开始，结合奖励差距、生成质量与通用能力评测做小范围扫描。

DPO 的主要局限是什么？

它是离线方法，只能在数据已有的回答之间学习偏好，无法探索更好的回答，且当模型分布偏离数据时效果下降；对偏好数据中的噪声和长度等偏差敏感。迭代式 DPO 或在线 RL 可缓解，对可验证任务常改用 RLVR。
