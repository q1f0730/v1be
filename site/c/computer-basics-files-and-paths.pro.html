文件、文件夹与路径

Computer Basics: Files & Paths

📐 01 · 定义

文件系统（File System）以树状目录组织文件，路径（Path）是定位某个文件或目录的字符串。路径分绝对路径（从根目录起）和相对路径（相对当前工作目录）。理解路径分隔符、当前目录、主目录和大小写规则，是写脚本、配置项目、让 Agent 正确读写文件的基础。

⚙️ 02 · 原理
  1. 1

    根目录：类 Unix 系统只有一个根「/」；Windows 每个盘符有自己的根，如 C:\。

  2. 2

    工作目录：每个进程有当前工作目录（cwd），相对路径都以它为起点解析。

  3. 3

    特殊符号：「.」表示当前目录，「..」表示上级目录，「~」在 shell 中展开为用户主目录。

  4. 4

    解析过程：系统逐级查找路径中的每一段目录，最终定位到文件或报「不存在」。

  5. 5

    权限检查：找到文件后，再按用户与权限位判断能否读、写或执行。

🔤 03 · 术语
绝对路径 (Absolute Path)
从根目录开始的完整路径，与当前目录无关。
相对路径 (Relative Path)
相对于当前工作目录的路径，换目录运行结果会变。
当前工作目录 (CWD)
进程当前所在目录，可用 pwd 查看。
路径分隔符 (Separator)
Unix 用「/」，Windows 原生用「\」，多数 API 也接受「/」。
符号链接 (Symlink)
指向另一个路径的特殊文件，类似快捷方式。
💻 04 · 代码
跨平台处理路径python
from pathlib import Path

print(Path.cwd())                 # 当前工作目录
print(Path.home())                # 用户主目录

# 以脚本自身位置为基准，避免「换个目录运行就找不到文件」
BASE = Path(__file__).resolve().parent
config = BASE / "config" / "settings.json"   # 用 / 拼接，自动适配系统分隔符

print(config)                     # 绝对路径
print(config.exists())            # 是否存在
print(config.suffix, config.stem) # .json  settings

# 相对路径 -> 绝对路径
print(Path("../data").resolve())

# 遍历目录下所有 .py 文件（递归）
for p in BASE.rglob("*.py"):
    print(p.relative_to(BASE))

用 pathlib 而不是手拼字符串，可自动处理分隔符并避免依赖当前工作目录。

⚖️ 06 · 方案取舍

绝对路径

优点无歧义，与运行位置无关

代价换机器或换用户就失效

适用系统级配置、一次性命令

相对于 CWD 的路径

优点简短

代价从别的目录运行会出错

适用交互式命令行操作

相对于项目根/脚本的路径

优点可移植、稳定

代价需在代码中计算基准目录

适用项目代码、脚本、配置

🕳️ 07 · 常见坑

  • ✗代码里写死 C:\Users\张三\project 这类路径

    ✓用项目相对路径或环境变量，保证他人和服务器可用

  • ✗在 macOS 上大小写写错也能跑，部署到 Linux 报找不到

    ✓引用文件名时严格匹配大小写

  • ✗路径含空格或中文时命令行未加引号

    ✓在 shell 中给路径加引号，或避免使用空格

  • ✗以为 ~ 在所有程序里都会展开

    ✓~ 是 shell 特性，代码中用 Path.home() 或 os.path.expanduser

🎤 09 · 面试追问
为什么脚本在 IDE 能跑，命令行就找不到文件？

相对路径基于当前工作目录解析。IDE 通常把项目根设为 CWD，而命令行在别的目录启动时 CWD 不同。解决：以脚本文件位置（__file__）或项目根为基准构造路径，或启动前 cd 到正确目录。

什么是路径穿越漏洞？

服务端直接把用户输入拼进文件路径，攻击者传入 ../../etc/passwd 之类的值读取越界文件。防御：规范化路径后校验是否仍在允许的根目录内，使用白名单文件名，不把用户输入直接作为路径。

Agent 操作文件时路径要注意什么？

确认 Agent 的工作目录与项目根一致；尽量让它使用项目内相对路径；限制可写目录范围；对删除、移动类操作要求确认。Claude Code 等工具默认以启动目录作为工作区边界。
