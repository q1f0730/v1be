🎯 一句话

把源代码打包成能上线的成品

🧸 打个比方

像中央厨房。生食材切好、配好、装盒。门店拿到就能直接卖。

  • 🏗️ 常见命令是npm run build
  • 📦 产出dist或build文件夹
  • 🔴 构建报错就不能上线，先修好

👣 你该怎么做

  1. 1

    🧪 上线前本地跑一次npm run build

  2. 2

    📋 报错就整段复制给AI

  3. 3

    ✅ 构建成功再部署

💥 翻车现场

小潘本地dev一切正常，没跑过build。一部署，类型错误满屏，上线失败。

🤖 复制给 AI 的话

请运行npm run build，如果报错，逐个分析原因并修复，直到构建成功，最后告诉我改了什么。

✅ 小测一下

上线前最好先在本地做什么？

💡 本地先构建，能提前发现上线会遇到的错。
