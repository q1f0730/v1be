🎯 一句话

HTTPS 是加了密的 HTTP

🧸 打个比方

HTTP 像寄明信片，邮递员都能看。HTTPS 像寄密封信，路上没人能偷看。

  • 📮 HTTP 传的内容路上能被偷看
  • 🔐 HTTPS 会把内容加密再传
  • 🌐 上线的网站一定要用 HTTPS
