模型蒸馏

📐 01 · 定义

模型蒸馏（Knowledge Distillation）是一种模型压缩与迁移方法：用大模型（教师）的输出分布或生成结果作为监督信号训练小模型（学生），让学生以更少参数和更低推理成本逼近教师效果。它常用于端侧部署、降本提速，以及把强模型能力迁移到专用小模型。

⚙️ 02 · 原理
  1. 1

    准备教师：选定效果好的大模型，冻结参数，只用于产生监督信号。

  2. 2

    产生软标签：对训练样本用带温度 T 的 softmax 得到概率分布，保留类别间相似度信息。

  3. 3

    或生成数据：在 LLM 场景常让教师生成回答/推理过程，作为学生的 SFT 数据（序列级蒸馏）。

  4. 4

    训练学生：损失通常为软标签 KL 散度（乘 T²）与真实标签交叉熵的加权和。

  5. 5

    评估部署：对比学生与教师在目标任务上的差距、延迟与成本，必要时再量化。

🔤 03 · 术语
软标签 (Soft Targets)
教师输出的完整概率分布，比 one-hot 标签包含更多信息。
温度 (Temperature)
softmax 前除以 T，T 越大分布越平滑，暴露更多次要类别信息。
暗知识 (Dark Knowledge)
教师对错误类别的相对概率中隐含的相似性知识。
序列级蒸馏 (Sequence-level KD)
用教师生成的完整输出序列作为学生的训练目标。
量化 (Quantization)
降低权重数值精度以压缩模型，常与蒸馏配合使用。
💻 04 · 代码
经典蒸馏损失python
import torch.nn.functional as F

def kd_loss(student_logits, teacher_logits, labels, T=2.0, alpha=0.5):
    # 软标签部分：学生与教师在温度 T 下的 KL 散度
    soft = F.kl_div(
        F.log_softmax(student_logits / T, dim=-1),
        F.softmax(teacher_logits / T, dim=-1),
        reduction="batchmean",
    ) * (T * T)          # 乘 T^2，保持梯度量级与温度无关
    # 硬标签部分：与真实标签的交叉熵
    hard = F.cross_entropy(student_logits, labels)
    return alpha * soft + (1 - alpha) * hard

# 训练循环中：教师 no_grad 前向，学生正常反向传播

Hinton 等提出的经典形式；T 与 alpha 是需要调的超参数。

🕳️ 07 · 常见坑

  • ✗用闭源模型输出蒸馏但忽视服务条款

    ✓先核对模型提供方的使用条款是否允许用输出训练其他模型

  • ✗教师数据覆盖面窄，学生在分布外样本上崩

    ✓按真实线上分布采样提示，覆盖长尾和边界情况

  • ✗只在训练集分布上评估学生效果

    ✓保留独立测试集，并与教师逐项对比失败案例

☑️ 08 · 检查清单
🎤 09 · 面试追问
为什么软标签比硬标签更有用？

硬标签只说明正确类别；软标签还体现教师认为哪些错误类别更相近，例如 2 像 3 而不像狗，这类相似结构提供了更多梯度信息，学生用更少数据学到更好的决策边界。

损失里为什么要乘 T²？

温度 T 下软标签梯度大约按 1/T² 缩小，乘 T² 可使软损失的梯度量级在不同温度下大致不变，便于与硬标签损失按 alpha 组合，避免调温度时还要重调权重。

LLM 时代的蒸馏和经典蒸馏有何不同？

大模型多通过 API 提供，拿不到 logits，常用教师生成的回答和推理链做 SFT（数据蒸馏）。重点转向提示多样性、数据筛选与质量控制，以及合规问题，而非损失函数设计。
