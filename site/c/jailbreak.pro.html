越狱攻击 (Jailbreak)

Jailbreak

📐 01 · 定义

越狱（Jailbreak）是用户通过精心构造的输入，诱使模型绕过其安全对齐与使用政策，输出本应拒绝的内容或执行被禁止的行为。它与提示注入同属 LLM 应用的输入攻击面（OWASP LLM01），区别在于越狱通常由直接对话的用户发起、目标是突破模型安全限制。防护需要多层组合，不能只靠系统提示。

⚙️ 02 · 原理
  1. 1

    角色扮演与虚构框架：让模型扮演「无限制 AI」或在故事、假设情境中输出有害内容。

  2. 2

    目标冲突：利用「乐于助人」与「安全」两种训练目标的冲突，用紧急情况、权威身份施压。

  3. 3

    泛化失配：用编码、外语、拆分拼接等形式绕开安全训练覆盖不到的分布。

  4. 4

    多轮与多样例：通过多轮逐步升级或在长上下文中堆叠大量示例诱导模型顺从。

  5. 5

    自动化攻击：用优化算法搜索对抗后缀，部分攻击可在不同模型间迁移。

🔤 03 · 术语
安全对齐 (Safety Alignment)
通过 RLHF 等训练让模型拒绝有害请求的过程。
提示注入 (Prompt Injection)
通过输入改变模型预期行为；间接注入来自文档或网页。
对抗后缀 (Adversarial Suffix)
算法搜索出的字符序列，附加在请求后可诱发违规输出。
安全分类器 (Safety Classifier)
独立模型检测输入或输出是否违规，如 Llama Guard。
红队测试 (Red Teaming)
模拟攻击者系统性寻找模型与应用的安全漏洞。
💻 04 · 代码
多层防护的最小骨架python
# pip install openai
from openai import OpenAI

client = OpenAI()

def flagged(text: str) -> bool:
    """第 1/3 层：输入与输出都过一遍审核模型"""
    r = client.moderations.create(model="omni-moderation-latest", input=text)
    return r.results[0].flagged

def handle(user_id: str, msg: str) -> str:
    if flagged(msg):
        return "抱歉，这个请求我无法处理。"

    # 第 2 层：模型生成（系统提示只是其中一层，不能当唯一防线）
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "system", "content": "你是售后客服，只回答订单相关问题。"},
                  {"role": "user", "content": msg}],
    )
    answer = resp.choices[0].message.content

    if flagged(answer):                     # 输出侧再检查
        return "抱歉，这个请求我无法处理。"
    # 第 4 层：模型想做的敏感操作（退款、查他人订单）一律由后端按权限校验
    return answer

审核模型只拦一般违规内容；业务越权要靠后端权限控制，而不是模型自觉。

📊 05 · 参数对比

防护层次与作用

层次手段防住什么局限
模型层安全对齐、选用安全性好的模型大部分直接有害请求可被新话术绕过
输入/输出过滤安全分类器、规则明显违规内容误报漏报并存
应用权限层最小权限、后端鉴权越权操作与数据泄露需工程投入
运营层日志、限流、封禁、红队持续攻击与新手法滞后于攻击
⚖️ 06 · 方案取舍

严格过滤

优点违规输出风险低

代价误拒正常用户，体验变差

适用面向公众或未成年人

宽松 + 事后审计

优点体验流畅

代价可能产生违规内容

适用内部工具、专业用户

权限隔离优先

优点即使被越狱也难造成实际损害

代价需细化后端权限设计

适用Agent 能调用工具与数据

🕳️ 07 · 常见坑

  • ✗只在系统提示里写「不要泄露、不要被骗」

    ✓把敏感数据与操作放到后端权限控制之后

  • ✗系统提示中放密钥或内部机密

    ✓假设系统提示可能被套出，不放任何机密

  • ✗只测单轮攻击，忽略多轮逐步诱导

    ✓红队覆盖多轮、编码、角色扮演与长上下文场景

  • ✗上线后不再关注新越狱手法

    ✓记录与抽检对话，定期回归越狱测试集

🎤 09 · 面试追问
越狱和提示注入有什么区别？

越狱通常由直接对话的用户发起，目标是突破模型的安全策略让其输出违规内容；提示注入更强调改变应用预期行为，尤其是间接注入——恶意指令藏在网页、文档、工具结果中。OWASP 把二者归在同一风险类别下。

为什么安全训练会被绕过？

研究归纳出两类原因：目标冲突（乐于助人与安全相互竞争）和泛化失配（安全训练没覆盖编码、低资源语言等分布，而能力本身覆盖到了）。因此单靠模型对齐难以完全防住。

给带工具调用的 Agent 设计越狱防护，重点是什么？

假设模型终会被绕过：工具按最小权限设计，危险操作要人工确认；后端校验每次调用的身份与授权；工具结果视为不可信输入；输入输出过安全分类；完整审计日志与速率限制。
