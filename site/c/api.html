🎯 一句话

程序之间互相点单的窗口

🧸 打个比方

API 像奶茶店的点单窗口。你不用进后厨。按菜单点单，奶茶就递出来。

  • 🍵 API 就是一份「能点什么」的菜单
  • 📮 你发请求，它回结果
  • 🤖 接 AI、地图、支付都靠 API

💥 翻车现场

没看文档乱填参数，接口一直回「400」，折腾了一下午。

🤖 复制给 AI 的话

请帮我调用这个天气 API：[文档链接]。先写一个最小测试，打印返回结果，再告诉我每个字段的意思。
