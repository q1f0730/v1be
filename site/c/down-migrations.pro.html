📐 01 · 定义

回滚迁移（Down Migration）是与升级迁移（Up）配对的逆向脚本，用于把数据库结构撤回到上一版本。它属于数据库变更管理层，主要用于开发环境来回切换和发布失败时的应急。由于删除列、改类型等操作会丢数据，生产中更常见的策略是“向前修复”加兼容性设计。

⚙️ 02 · 原理
  1. 1

    迁移工具为每个版本维护一对脚本：upgrade/up 前进，downgrade/down 撤销。

  2. 2

    工具在数据库内的版本表（如 alembic_version）记录当前版本，按顺序执行或回退。

  3. 3

    down 必须逆序撤销 up 的每一步，例如先删索引再删列。

  4. 4

    破坏性变更（删列、删表、收窄类型）的 down 无法恢复数据，只能恢复结构。

  5. 5

    生产常采用扩展-收缩（expand-contract）：先加兼容结构，代码切换稳定后再删旧结构。

🔤 03 · 术语
Schema Migration
版本化、可重复执行的数据库结构变更脚本。
Roll Forward
出问题时发布一个新迁移修复，而非回退旧迁移。
扩展-收缩 (Expand-Contract)
先兼容新增、后清理旧结构的分阶段变更模式。
事务性 DDL (Transactional DDL)
DDL 可在事务中回滚；PostgreSQL 支持，MySQL 多数 DDL 会隐式提交。
不可逆迁移 (Irreversible Migration)
down 无法还原数据的迁移，应显式标注。
💻 04 · 代码
Alembic 成对迁移python
"""add users.nickname"""
from alembic import op
import sqlalchemy as sa

revision = "a1b2c3d4e5f6"
down_revision = "9f8e7d6c5b4a"

def upgrade():
    # 扩展阶段：只新增可空列，旧代码不受影响
    op.add_column("users", sa.Column("nickname", sa.String(64), nullable=True))
    op.create_index("ix_users_nickname", "users", ["nickname"])

def downgrade():
    # 逆序撤销：先删索引，再删列（该列数据会丢失）
    op.drop_index("ix_users_nickname", table_name="users")
    op.drop_column("users", "nickname")

# 命令行：
#   alembic upgrade head     升级到最新
#   alembic downgrade -1     回退一个版本
#   alembic upgrade head --sql   只生成 SQL 供评审

down 与 up 严格逆序；新增可空列属于可安全回退的扩展型变更。

⚖️ 06 · 方案取舍

维护 down 脚本

优点开发环境可来回切换，应急有预案

代价维护成本高，常年不测易失效

适用开发频繁切分支的团队

只向前修复

优点流程单一，避免回退丢数据

代价出错时需快速写修复迁移

适用生产环境的主要策略

备份/快照回滚

优点可恢复数据本身

代价会丢失快照之后的写入

适用灾难性错误的最后手段

🕳️ 07 · 常见坑

  • ✗down 脚本从未执行过，出事时才发现跑不通

    ✓CI 中执行 up→down→up 验证可逆性

  • ✗同一次发布里改代码又删旧列

    ✓按扩展-收缩拆成多次发布

  • ✗以为 down 能恢复被删列的数据

    ✓破坏性变更前备份或保留影子列一段时间

  • ✗在 MySQL 中依赖事务回滚失败的 DDL

    ✓了解 DDL 隐式提交，单个迁移只做一类变更

🎤 09 · 面试追问
为什么生产上更推荐向前修复？

回退迁移可能丢失新写入的数据，且应用代码可能已依赖新结构；在压力下执行少测的 down 风险高。向前修复配合扩展-收缩，让每一步都兼容新旧代码，代码可独立回滚而数据库不用退。

如何安全地重命名一列？

不直接 RENAME。先加新列，代码双写新旧列并回填历史数据；读取切到新列并观察；确认旧代码不再运行后停止写旧列；最后单独发布删除旧列。每一步都可单独回退。

AI 生成的迁移需要重点审什么？

是否有删列删表等破坏性操作、down 是否真正逆序、大表上是否会长时间锁表（如加非空默认值、建索引未用 CONCURRENTLY），以及是否混入了与需求无关的自动生成变更。
