🎯 一句话

让浏览器以后只走加密的 HTTPS。

🧸 打个比方

提前叮嘱顾客：只坐运钞车来办业务。有人叫你上三轮车，千万别上。

  • 🔓 HTTP 不加密，路上能被偷看。
  • 🔒 HTTPS 加密，内容别人看不懂。
  • 📌 HSTS：让浏览器只走 HTTPS。

📊 开 vs 不开 HSTS

对比项✅ 开启❌ 不开
首次访问后只走 HTTPS可能走 HTTP
公共 Wi-Fi难被劫持易被劫持
设置加一个响应头什么都不做

👣 你该怎么做

  1. 1

    🔒 先确认网站已能正常 HTTPS。

  2. 2

    🤖 让 AI 加上 HSTS 响应头。

  3. 3

    🧪 用检测网站确认已生效。

💥 翻车现场

用户在咖啡店连 Wi-Fi，网址走了 HTTP。登录密码被同网的人截获。

🤖 复制给 AI 的话

请在服务器配置 Strict-Transport-Security 响应头，max-age 设为一年，并把 HTTP 请求全部跳转到 HTTPS。
