📐 01 · 定义

框架（Framework）是提供应用骨架和约定的可复用代码体系，开发者在其规定的扩展点中填写业务代码，由框架负责调用。与库相比，框架掌握控制流，即控制反转（Inversion of Control）。它内置路由、渲染、数据访问、安全等通用能力，以「约定优于配置」换取开发效率和团队一致性。

⚙️ 02 · 原理
  1. 1

    定义结构：框架约定目录、文件命名和配置方式，如路由文件放在特定目录。

  2. 2

    接管控制流：框架负责启动应用、接收请求或事件，并调度到你注册的代码。

  3. 3

    提供扩展点：通过回调、装饰器、中间件、生命周期钩子注入业务逻辑。

  4. 4

    内置通用能力：路由、模板或组件渲染、ORM、鉴权、表单校验等开箱即用。

  5. 5

    生态扩展：插件和社区包围绕框架约定构建，形成可组合的解决方案。

🔤 03 · 术语
控制反转 (IoC)
由框架调用你的代码，而非你调用框架。
约定优于配置 (CoC)
遵循默认约定即可工作，只有例外才需配置。
中间件 (Middleware)
插入请求处理链中的通用逻辑单元。
生命周期钩子 (Lifecycle Hooks)
在组件或应用特定阶段被调用的函数。
脚手架 (Scaffolding)
按框架约定自动生成项目初始结构的工具。
💻 04 · 代码
Express：框架调用你的代码javascript
// npm install express ；运行：node app.js
const express = require("express");
const app = express();

app.use(express.json());            // 框架内置中间件：解析 JSON 请求体

// 你只注册处理函数，何时调用由框架决定（控制反转）
app.get("/api/health", (req, res) => {
  res.json({ ok: true });
});

app.post("/api/echo", (req, res) => {
  if (!req.body?.text) {
    return res.status(400).json({ error: "text is required" });
  }
  res.json({ echo: req.body.text });
});

// 错误处理中间件：四个参数是 Express 的约定
app.use((err, req, res, next) => {
  console.error(err);
  res.status(500).json({ error: "internal error" });
});

app.listen(3000, () => console.log("http://localhost:3000"));

你写处理函数，框架负责监听、路由分发和调用，这就是框架与库的本质区别。

全功能框架（Django、Rails）

🎤 09 · 面试追问
库和框架的核心区别是什么？

控制权。使用库时你的代码掌握流程，在需要时调用库；使用框架时框架掌握流程，在约定的时机调用你的代码（控制反转）。因此框架影响整个项目结构，替换成本远高于替换一个库。

React 是库还是框架？

React 官方自称用于构建界面的库，只负责组件渲染；路由、数据获取等需要另选。但实践中它主导了应用结构，生态也常被称为框架。Next.js 等元框架在 React 之上补齐路由和服务端能力，是更完整的框架。

AI 写代码时如何避免框架版本混乱？

在 CLAUDE.md 或规则文件中声明框架与主版本；锁定依赖版本；让 Agent 先读取 package.json 等清单再动手；提供或检索对应版本的官方文档；用类型检查与构建作为验证，及时发现过时 API。
