🎯 01 · 一句话

Google 用来给网页体验打分的指标

🧸 02 · 打个比方

像餐厅的服务评分。上菜快不快，叫服务员应不应，桌子晃不晃。三项都要好。

  • 🚀 LCP：主要内容多快出来
  • 👆 INP：点击后多快有反应
  • 🧱 CLS：页面会不会乱跳
