🎯 一句话

给运行中的程序做体检，找出最耗资源处

🧸 打个比方

给跑步运动员戴上监测仪。每隔一会拍一下全身。找出哪块肌肉最累。

  • 🩺 程序跑着时持续采样
  • 🔥 找出最吃 CPU 或内存的函数
  • 🎯 精准优化，不再瞎猜

小周的 CPU 飙到100%，他凭感觉改了三个函数，结果都不是真凶。

我的接口 CPU 很高。请教我怎么对它做性能剖析，并根据结果找出最耗时的函数给出优化方案。
