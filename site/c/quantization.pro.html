📐 01 · 定义

模型量化（Quantization）是把神经网络权重（有时也包括激活值和 KV 缓存）从 FP16/BF16 等高精度格式转换为 INT8、INT4 等低位宽表示的压缩技术。它属于模型推理优化层，用少量精度损失换取更小的显存占用、更低的内存带宽需求和更快的推理速度，是本地运行大模型的关键前提。

⚙️ 02 · 原理
  1. 1

    把一组浮点权重映射到有限个整数级别，并为每组保存缩放因子（scale），必要时还有零点。

  2. 2

    按块或按通道分组量化，组越小精度越高，但额外存储的缩放因子越多。

  3. 3

    训练后量化（PTQ）直接对现成模型量化，可用少量校准数据减少误差，如 GPTQ、AWQ。

  4. 4

    推理时把低位权重按需反量化参与计算，或直接用支持低精度的计算内核。

  5. 5

    量化后在评测集上对比困惑度和下游任务指标，确认精度损失在可接受范围。

🔤 03 · 术语
训练后量化 (PTQ)
模型训练完成后再量化，无需重新训练。
量化感知训练 (QAT)
训练中模拟量化误差，精度通常更好但成本高。
GPTQ
基于近似二阶信息逐层量化权重的 PTQ 方法。
AWQ
根据激活重要性保护关键权重的仅权重量化方法。
NF4
QLoRA 提出的 4 位 NormalFloat 数据类型。
💻 04 · 代码
4 位量化加载模型python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig

model_id = "Qwen/Qwen2.5-1.5B-Instruct"

bnb = BitsAndBytesConfig(
    load_in_4bit=True,                     # 权重以 4 位存储
    bnb_4bit_quant_type="nf4",             # NormalFloat4
    bnb_4bit_compute_dtype=torch.bfloat16, # 计算时用 bf16
    bnb_4bit_use_double_quant=True,        # 对缩放因子再量化
)

tok = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id, quantization_config=bnb, device_map="auto"  # 需要 CUDA GPU
)
print(f"显存占用约 {model.get_memory_footprint() / 1e9:.2f} GB")

inputs = tok("量化的代价是什么？", return_tensors="pt").to(model.device)
out = model.generate(**inputs, max_new_tokens=60)
print(tok.decode(out[0], skip_special_tokens=True))

bitsandbytes 在加载时即时量化；本地推理常用的 GGUF 量化则是预先转换好的文件。

📊 05 · 参数对比

精度与显存（权重部分）

格式每参数约占7B 模型权重约精度影响
FP16/BF162 字节14 GB基准
INT81 字节7 GB通常很小
4 位约 0.5 字节约 4 GB小到中等，依方法而定
2–3 位更少更少明显下降
⚖️ 06 · 方案取舍

8 位量化

优点精度几乎无损，显存减半

代价压缩比有限

适用精度敏感、显存够用

4 位量化

优点显存约为 FP16 的四分之一

代价部分任务质量下降

适用本地运行、消费级 GPU

更大模型 + 低位量化

优点常优于同显存的小模型全精度

代价极低位时质量崩溃

适用显存受限但想要更强能力

🕳️ 07 · 常见坑

  • ✗只看显存，不评测量化后的任务效果

    ✓用自己的评测集对比量化前后指标

  • ✗以为量化后显存只取决于权重大小

    ✓预留 KV 缓存与运行开销，长上下文占用显著

  • ✗混用不兼容的量化格式与推理引擎

    ✓按引擎选择格式：llama.cpp 用 GGUF，GPU 服务常用 AWQ/GPTQ

  • ✗对代码、数学等敏感任务用过低位宽

    ✓这类任务优先 8 位或较高质量的 4 位方案

☑️ 08 · 检查清单
🎤 09 · 面试追问
为什么量化能加速推理？

LLM 解码阶段通常受内存带宽限制，每生成一个 token 都要读取全部权重。位宽降低使读取的数据量成比例减少；若硬件支持低精度计算，算力利用也会提升。

GPTQ 和 AWQ 的区别？

两者都是仅权重的训练后量化。GPTQ 逐层利用近似二阶信息补偿量化误差；AWQ 根据激活分布找出少量关键权重通道并加以保护。实际效果因模型而异，需评测选择。

KV 缓存也能量化吗？

可以。长上下文时 KV 缓存可能占用大量显存，将其量化到 8 位甚至更低能支持更长上下文或更多并发，但可能影响长距离信息的准确性，需要评测。
