注意力机制 (Self-Attention)

Attention Mechanism

📐 01 · 定义

注意力机制（Attention）让模型在处理某个位置时，按相关性对序列中其他位置的信息加权求和。Transformer 使用缩放点积自注意力：每个 token 生成查询（Q）、键（K）、值（V）三个向量，用 Q·K 计算相关分数并 softmax 归一化后加权 V。它决定了长上下文的计算与显存成本，是理解 KV 缓存与上下文定价的基础。

⚙️ 02 · 原理
  1. 1

    输入向量分别乘以三个可学习矩阵，得到每个 token 的 Q、K、V；Q 代表“我在找什么”，K 代表“我能提供什么”。

  2. 2

    计算 Q 与所有 K 的点积并除以 √d_k 缩放，防止数值过大导致 softmax 饱和、梯度变小。

  3. 3

    解码器施加因果掩码，把未来位置的分数设为负无穷；softmax 后得到每行和为 1 的注意力权重。

  4. 4

    用权重对 V 加权求和，得到融合上下文的新表示；多头注意力并行做多组投影，再拼接后线性变换。

  5. 5

    序列长度为 n 时，分数矩阵为 n×n，计算量随 n 平方增长；推理时缓存历史 K、V（KV 缓存）避免重复计算。

🔤 03 · 术语
查询/键/值 (Q/K/V)
由同一输入经不同线性投影得到，用于计算相关性与聚合信息。
缩放点积 (Scaled Dot-Product)
softmax(QKᵀ/√d_k)V，Transformer 的标准注意力公式。
多头注意力 (Multi-Head Attention)
多组 Q/K/V 并行计算，捕捉不同类型的关系。
KV 缓存 (KV Cache)
生成时保存已算过的 K、V，新 token 只需算自己的那一行。
GQA (Grouped-Query Attention)
多个查询头共享一组 K/V 头，显著减小 KV 缓存。
FlashAttention
按块计算、减少显存读写的精确注意力实现，速度更快、省显存。
💻 04 · 代码
NumPy 实现因果自注意力python
import numpy as np

def softmax(x):
    x = x - x.max(-1, keepdims=True)   # 数值稳定
    e = np.exp(x)
    return e / e.sum(-1, keepdims=True)

def causal_attention(Q, K, V):
    n, d_k = Q.shape
    scores = Q @ K.T / np.sqrt(d_k)    # n x n 相关分数
    mask = np.triu(np.ones((n, n)), k=1).astype(bool)
    scores[mask] = -np.inf             # 看不到未来 token
    w = softmax(scores)                # 每行和为 1
    return w @ V, w

rng = np.random.default_rng(0)
n, d = 4, 8
Q, K, V = (rng.standard_normal((n, d)) for _ in range(3))
out, w = causal_attention(Q, K, V)
print(np.round(w, 2))                  # 下三角权重矩阵

演示 QKᵀ/√d、因果掩码和 softmax 加权；n×n 矩阵就是长上下文成本的来源。

⚖️ 06 · 方案取舍

全量注意力

优点任意位置直接交互，效果最好

代价O(n²) 计算，长序列昂贵

适用上下文中等、追求质量

稀疏/滑动窗口注意力

优点长序列成本接近线性

代价远距离信息需多层间接传递

适用超长文本、流式输入

检索后只放相关片段

优点输入短，成本和延迟低

代价依赖检索质量

适用应用层控制长文档成本

🕳️ 07 · 常见坑

  • ✗认为上下文窗口越大越好，全量塞入资料

    ✓注意力成本随长度增长且中段易被忽略，先检索筛选相关内容

  • ✗估算显存只看模型权重

    ✓长上下文和高并发下 KV 缓存可与权重同量级，需按层数、头数、长度估算

  • ✗把注意力权重当作可靠的模型解释

    ✓注意力权重不等于因果贡献，解释性结论需谨慎

  • ✗自己实现 softmax 不做数值稳定处理

    ✓减去每行最大值再求指数，避免溢出

🎤 09 · 面试追问
为什么要除以 √d_k？

假设 Q、K 分量独立且方差为 1，点积方差约为 d_k。维度大时分数绝对值很大，softmax 会接近 one-hot，梯度几乎为零。除以 √d_k 把方差拉回约 1，使训练稳定。

KV 缓存为什么能加速生成？

自回归生成时，历史 token 的 K、V 不会改变。缓存后每步只为新 token 计算 Q、K、V，并与缓存做一行注意力，避免重算整段序列。代价是显存随序列长度和并发线性增长，这也是长对话推理昂贵的原因之一。

自注意力和交叉注意力有什么不同？

自注意力的 Q、K、V 来自同一序列；交叉注意力的 Q 来自一个序列（如解码器），K、V 来自另一个序列（如编码器输出或图像特征）。翻译模型和许多多模态模型用交叉注意力把两种信息对齐。
