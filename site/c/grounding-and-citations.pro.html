有据生成与引用溯源

Grounding & Citations

📐 01 · 定义

有据生成（Grounding）指让模型的回答建立在显式提供的外部证据上（检索到的文档、搜索结果、数据库记录），引用溯源（Citations）则把回答中的具体论断与证据片段一一对应。它属于 LLM 应用的可信度层，是 RAG 与联网搜索产品的核心要求，用于降低幻觉并让用户能够核查。

⚙️ 02 · 原理
  1. 1

    检索或接收证据：通过 RAG、搜索 API 或用户上传获得文档，并切分为可引用的片段，保留来源元数据。

  2. 2

    构造提示：把证据连同编号或标题放入上下文，并指示模型只依据证据作答、证据不足时明确说明。

  3. 3

    生成带引用的回答：模型在论断后标注来源编号；部分 API 原生返回引用的字符或页码范围。

  4. 4

    后处理校验：检查引用是否存在、被引片段是否真正支持该论断，必要时删除或重写不受支持的句子。

  5. 5

    前端呈现：引用可点击跳转到原文高亮处，让用户低成本核查。

🔤 03 · 术语
有据性 (Groundedness / Faithfulness)
回答内容能被所给证据支持的程度。
引用准确率 (Citation Precision)
所给引用中真正支持对应论断的比例。
引用召回率 (Citation Recall)
需要引用的论断中确实给出了支持引用的比例。
归因 (Attribution)
把生成内容追溯到具体来源片段的过程。
拒答 (Abstention)
证据不足时明确表示无法回答，而不是猜测。
💻 04 · 代码
Anthropic Citations 接口python
# pip install anthropic
import anthropic

client = anthropic.Anthropic()
contract = open("contract.txt", encoding="utf-8").read()

msg = client.messages.create(
    model="claude-sonnet-4-5",  # 换成你在用的模型
    max_tokens=1024,
    messages=[{"role": "user", "content": [
        {"type": "document",
         "source": {"type": "text", "media_type": "text/plain", "data": contract},
         "title": "服务合同",
         "citations": {"enabled": True}},   # 开启原生引用
        {"type": "text", "text": "违约金条款是怎么约定的？资料中没有就直说。"},
    ]}],
)

for block in msg.content:
    if block.type == "text":
        print(block.text)
        for c in block.citations or []:      # 每段文字对应的原文出处
            print("  ↳ 引用:", c.cited_text[:60])

原生引用返回被引原文与位置，比让模型自己写编号更可靠，但仍需抽检是否真正支持论断。

⚖️ 06 · 方案取舍

严格只用证据

优点幻觉少、可审计

代价证据缺失时回答受限

适用法律、医疗、客服知识库

证据 + 模型常识

优点回答更完整流畅

代价混入无出处内容，难核查

适用通用助手，需标明哪些无出处

生成后逐句校验

优点显著提升引用准确率

代价额外延迟与费用

适用高风险输出

🕳️ 07 · 常见坑

  • ✗有引用标记就默认内容正确

    ✓评测引用准确率，抽检被引片段是否真正支持论断

  • ✗检索质量差，模型只能基于无关片段作答

    ✓先优化检索与重排，并在证据不足时触发拒答

  • ✗切片丢失来源元数据，无法回链原文

    ✓每个片段保存文档 ID、页码或段落位置

  • ✗提示允许模型「补充」，导致无出处内容混入

    ✓明确区分有据部分与推断部分，或禁止补充

🎤 09 · 面试追问
如何评估 RAG 回答的有据性？

构建带标准证据的评测集；逐句判断论断是否被检索片段蕴含（可用 NLI 模型或 LLM 评审并人工抽检）；同时统计引用准确率与召回率、拒答是否恰当，并把检索质量与生成质量分开度量。

原生引用 API 相比提示里要求标号有什么优势？

原生引用由系统把输出片段与输入文档的具体位置绑定，返回被引原文，减少编造编号或错位；前端可直接高亮原文。但它不保证论断语义上被完整支持，仍需评测。

证据之间互相矛盾怎么办？

提示中要求模型显式指出冲突并分别引用；按来源权威性、时间新旧设置优先级；必要时把冲突呈现给用户而非擅自裁决；检索阶段可按版本或日期过滤过期文档。
