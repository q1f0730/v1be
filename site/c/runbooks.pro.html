标准化运维操作手册

Runbooks

📐 01 · 定义

运维手册（Runbook）是针对特定告警、故障或例行操作编写的标准化步骤文档，说明触发条件、影响判断、诊断命令、处置动作、验证方法和升级路径。它是事件响应与值班体系的执行层，把专家经验固化为任何值班者都能照做的流程，降低恢复时间对个人的依赖，也是逐步自动化的起点。

⚙️ 02 · 原理
  1. 1

    每条呼叫级告警关联一份手册，常通过告警注解中的 runbook_url 直接跳转。

  2. 2

    手册开头说明这条告警的含义、可能造成的用户影响，以及判断严重度的方法。

  3. 3

    列出按顺序执行的诊断命令和预期输出，帮助值班者快速缩小范围。

  4. 4

    给出具体的处置步骤与回滚方式，醒目标注危险操作和需要审批或双人确认的步骤。

  5. 5

    写明恢复验证标准和升级联系人，并在每次使用后更新，逐步把稳定步骤脚本化。

🔤 03 · 术语
Playbook
常与 Runbook 混用，有时指更高层的应对策略集合。
runbook_url 注解
Prometheus 告警规则中约定俗成的注解字段，用于链接手册。
可执行手册 (Executable Runbook)
把步骤做成可一键运行的脚本或自动化工作流。
升级路径 (Escalation Path)
手册无法解决时应联系的人和团队顺序。
琐事 (Toil)
手动、重复、可自动化且无持久价值的运维工作。
💻 04 · 代码
Pod 频繁重启处置手册bash
# Runbook: KubePodCrashLooping（api 命名空间）
# 影响：重启期间该 Pod 不接流量；若全部副本异常则服务不可用

# 1. 看范围：多少副本在重启？
kubectl -n api get pods -l app=api

# 2. 看上一次崩溃的日志和退出原因（OOMKilled / Error）
kubectl -n api logs deploy/api --previous --tail=100
POD=$(kubectl -n api get pods -l app=api -o name | head -n1)
kubectl -n api describe "$POD" | grep -A5 'Last State'

# 3. 是否与最近发布相关？
kubectl -n api rollout history deploy/api

# 4. 处置：若与发布相关，回滚到上一版本
kubectl -n api rollout undo deploy/api

# 5. 验证：所有 Pod Ready 且错误率回落
kubectl -n api rollout status deploy/api
# 未解决：升级到 #team-api 负责人

手册按范围、原因、关联变更、处置、验证、升级排列，命令均可直接执行。

📊 05 · 参数对比

手册质量分级

等级形态特点
无只在专家脑中恢复依赖特定人员
文档化步骤与命令清单可照做，需人工执行
半自动脚本执行诊断与常规处置人判断、机器执行
全自动告警触发自动修复需完善的安全护栏
⚖️ 06 · 方案取舍

详细的手动手册

优点灵活，人可判断

代价执行慢，易遗漏步骤

适用罕见或高风险故障

脚本化手册

优点快速、可重复

代价需维护脚本，异常场景覆盖有限

适用频繁发生且步骤固定

自动修复

优点无需人工介入

代价可能掩盖根因或误操作

适用处置低风险且已充分验证

🕳️ 07 · 常见坑

  • ✗手册写成背景介绍，值班时找不到该执行哪条命令。

    ✓开门见山给诊断与处置步骤，背景放附录。

  • ✗手册多年未更新，命令和资源名早已变化。

    ✓每次使用后更新，并在演练中定期验证。

  • ✗危险命令没有标注，值班者误删生产数据。

    ✓高危操作醒目标注，要求二人确认或审批。

  • ✗同一问题反复手动执行同样步骤。

    ✓高频步骤脚本化，最终考虑自动修复。

🎤 09 · 面试追问
一份好的 Runbook 应包含什么？

告警含义与影响，判断严重度的方法，按顺序的诊断命令及预期结果，处置与回滚步骤，验证恢复的标准，升级联系人，以及负责人和更新时间。目标是让不熟悉该服务的值班者也能处理。

Runbook 和自动化是什么关系？

手册是自动化的前身。先把经验写成明确步骤，在实践中验证；高频且确定的步骤脚本化；最后对低风险场景实现自动修复。始终保留手动路径以应对自动化失败。

AI Agent 适合执行 Runbook 吗？

适合执行只读的诊断步骤和整理信息，能节省值班者时间；写操作应要求人确认，权限最小化并全程留痕。手册写得越结构化，Agent 执行越可靠。
