📐 01 · 定义

搜索引擎优化（SEO）是让页面能被搜索引擎顺利抓取、渲染、索引，并在相关查询中获得更好展示的一组技术与内容实践。技术 SEO 关注可抓取性、渲染方式、规范链接、站点地图、结构化数据与页面体验；内容 SEO 关注满足搜索意图。对 AI 生成的前端项目，渲染方式与元信息是最常见的短板。

⚙️ 02 · 原理
  1. 1

    抓取：爬虫发现 URL（链接、sitemap），遵守 robots.txt 规则请求页面。

  2. 2

    渲染：Google 可执行 JavaScript，但渲染可能延后；服务端输出的 HTML 最可靠。

  3. 3

    索引：解析标题、正文、链接、结构化数据与 canonical，判断重复页与首选 URL；noindex 页面不入索引。

  4. 4

    排序：依据相关性、内容质量、链接信号与页面体验等众多因素决定展示位置。

  5. 5

    监测：通过 Search Console 等站长工具查看覆盖率、抓取错误、查询词与点击。

🔤 03 · 术语
robots.txt
告诉爬虫哪些路径可抓取；禁止抓取不等于禁止索引。
noindex
通过 meta 标签或响应头告知搜索引擎不要索引该页。
规范链接 (Canonical)
在重复或相似页面中声明首选 URL。
结构化数据 (Structured Data)
用 schema.org 词汇（常为 JSON-LD）描述页面实体。
XML Sitemap
列出希望被抓取的 URL 及更新时间的文件。
💻 04 · 代码
页面元信息与爬虫配置text
<!-- 每个页面独立的 head 信息 -->
<head>
  <title>手冲咖啡入门指南 | 咖啡小站</title>
  <meta name="description" content="从器具到萃取比例，10 分钟学会第一杯手冲。">
  <link rel="canonical" href="https://example.com/guides/pour-over">
  <script type="application/ld+json">
  {"@context": "https://schema.org", "@type": "Article",
   "headline": "手冲咖啡入门指南", "datePublished": "2026-10-20"}
  </script>
</head>

# robots.txt（放在站点根目录）
User-agent: *
Disallow: /admin/
Sitemap: https://example.com/sitemap.xml

<!-- 不希望被索引的页面用 noindex，而不是只在 robots.txt 禁止抓取 -->
<meta name="robots" content="noindex">

robots.txt 只管抓取；要让页面不出现在结果中，需允许抓取并返回 noindex。

SSR/SSG 输出 HTML

优点抓取最可靠、首屏快

代价需框架与服务端/构建支持

适用需要自然搜索流量的页面

CSR + 依赖搜索引擎渲染

优点架构简单

适用SEO 不重要的应用

程序化批量生成页面

优点覆盖大量长尾词

代价易被判为低质量重复内容

适用有真实独特数据支撑时

🕳️ 07 · 常见坑

  • ✗用 robots.txt 屏蔽页面，期望它从结果中消失

    ✓允许抓取并使用 noindex，确认移除后再视需要屏蔽

  • ✗staging 环境被索引或生产误带 noindex

    ✓预发环境加认证或 noindex，上线检查清单核对 robots 设置

  • ✗SPA 所有路由共用同一 title 与描述

    ✓按路由生成元信息，优先 SSR/SSG 输出

  • ✗同一内容多个 URL（参数、大小写、尾斜杠）

    ✓统一 URL 规范，301 重定向并设置 canonical

🎤 09 · 面试追问
robots.txt 的 Disallow 和 noindex 有什么区别？

Disallow 阻止爬虫抓取内容，但若有外部链接，URL 仍可能以无摘要形式被索引；noindex 要求不索引页面，但爬虫必须能抓到页面才能看到该指令。二者同时使用会使 noindex 失效。

JavaScript 渲染的网站如何做 SEO？

优先 SSR/SSG 或预渲染输出完整 HTML；确保链接是真实的 a 标签；资源可被抓取不被 robots 屏蔽；每个路由有独立元信息与可访问 URL；用 Search Console 的网址检查工具验证渲染结果。

结构化数据能直接提升排名吗？

官方说法是结构化数据帮助理解内容，并可能使页面获得富媒体结果展示，从而影响点击率；它本身不是直接的排名保证。标记必须与页面可见内容一致，否则可能被视为违规。
